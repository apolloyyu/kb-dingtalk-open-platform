# Tower群机器人接入

1. 进入Tower对应项目的**设置**。

2. 点击**添加Webhook**。

   ![1554966496995-ac78147c-13ac-4f87-9206-3607879b6071.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2924199951/p131246.png)
3. 填入Webhook地址。

   ![1554966496988-6ea4d366-ff11-4875-8695-e9fac3327c86.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2924199951/p131247.png)
