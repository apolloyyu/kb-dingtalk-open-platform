# 概述

## **什么是 HCM 主数据**

HCM 主数据是组织变革旗下 HCM 产品底层的主数据平台，用于对接 HCM 产品用户组织相关的人员、业务等主数据，进而支持用户在HCM产品中使用自己业务中的数据。
