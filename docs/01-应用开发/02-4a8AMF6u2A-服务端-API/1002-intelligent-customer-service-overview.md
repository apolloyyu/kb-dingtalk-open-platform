# 概述

本文介绍什么是智能客服，如何开通智能客服，以及智能客服接口能力等。

## 什么是智能客服

智能客服是一个企业进行内部或者外部服务的智能客服平台，深度地融合了在线客服工作台、智能机器人、工单系统和数据看板等，是基于钉钉的多渠道一站式智能客服系统。![智能客服q](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1370154871/p448077.png)

## 如何开通智能客服

以PC端开通智能客服为例：

步骤一：打开钉钉PC端，单击**工作台**。

步骤二：在工作台页面，单击**应用中心**。

步骤三：在应用中心页面，在**搜索框**输入**智能客服**。

步骤四：单击搜索出的**智能客服**应用。

步骤五：在**智能客服**产品详情页，单击**立即开通**。
