# 高级版编辑器

## 界面总览

高级版编辑器由四个核心区域组成：

| 区域 | 位置 | 核心功能 |
| --- | --- | --- |
| 顶部操作栏 | 图示① | 返回、保存、发布、导入导出等全局操作。 |
| 菜单面板区 | 图示② | 大纲树、组件库、预设模板、数据源管理。 |
| 编辑画板区 | 图示③ | 可视化布局调整与组件编辑。 |
| 组件属性设置区 | 图示④ | 选中组件的样式、内容、数据绑定配置。 |

![1642647985972-16193de7-8a79-49c3-8061-8851f4982979.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0260662461/p389775.png)

平台内置多种预设模板，帮助快速启动开发：

- **日志模板**：适用于工作日志、日报场景。
- **审批模板**：适用于请假、报销等审批流程。
- **日程模板**：适用于会议、活动提醒。
- **数据模板**：适用于数据统计、报表展示。
- **圈子模板**：适用于社区、讨论区场景。
- **链接模板**：适用于外部链接跳转。

首次使用建议从相似场景模板入手进行修改。

## 顶部操作栏

顶部操作栏分为左右两部分：

### **左半部分**

如下图所示，包含**返回按钮**和**模板名称**。

![1642647986393-c47c0d62-226a-4155-a2b6-495cc355c125.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0969562461/p389776.png)

点击返回按钮可回到**卡片模板列表页**。

![1642647986799-0f305ff1-01fa-4704-a8da-d37af3ad3266.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7065806871/p389777.png)

### **右半部分**

从左到右依次为：

![1642647987238-3a33ae38-cb5c-4051-8988-344d873f3392.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0969562461/p389778.png)

| 按钮 | 功能说明 |
| --- | --- |
| 后退/前进 | 撤销或还原上次的编辑操作。 |
| 更新日志 | 查看编辑器版本更新记录与新功能说明。 |

## 菜单面板区

如图所示，左侧菜单面板区共分为四个模块，从上往下分别是：**大纲树**、**组件库**、**预设模板**以及**数据源**。

![1642647987739-3d9d976c-44a0-47f6-8af8-a7f78735d211.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389779.png)

### **大纲树面板**

大纲树提供**当前卡片的总览视角**，能够直观的看到当前卡片的所有组件以及嵌套信息，并进行快速选中和拖拽操作。

选中某个组件时，编辑画板中对应的组件会同步高亮，便于在组件较多时定位目标。

![1642647988779-eb4ad0ba-13ee-4b6d-9160-b5494d1f2227.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7065806871/p389780.png)

### **组件库面板**

组件库是编辑卡片的核心区域。通过**长按拖拽**不同组件到画板，即可组合成最终的互动卡片。

组件按功能分为四类：

- **头部元素**：标题、副标题等顶部信息区组件。
- **内容元素**：文本、图片、图标等内容展示组件。
- **布局元素**：容器、行列等布局控制组件。
- **操作区**：按钮、链接等交互组件。

一个完整的互动卡片需要这四类元素的配合，拖动不同的组件到画板区，就可以生成不同的互动卡片。拖拽过程中，右侧大纲树会实时显示组件的嵌套位置。

![1642647989470-27ec5795-f3cb-4064-839b-d30cde8460ee.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7065806871/p389781.png)

### **预设模板面板**

预设模板面板中包含了许多常见的卡片模板，如日志模板、审批模板、日程模板等。每个预设模板提供两个操作：

- **使用**：将当前模板内容替换为预设模板（会覆盖当前正在编辑的内容）。
- **预览**：跳转至该模板的搭建态页面进行预览，不影响当前编辑中的模板。

![1642647990029-cc8fee2b-cb65-4025-a657-339799c9788f.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389782.png)

### **数据源面板**

数据源面板包含**变量列表**和**卡片模拟数据**（以下称为 Mock 数据）两部分。

#### **变量列表**

该面板展示了当前卡片所有变量的列表，并可以在此进行变量的增删改操作。

**变量为动态卡片提供数据支撑**，没有变量的卡片内容是固定不变的。

![1642647990436-7ffb0bf2-266f-4cef-9968-e31990ca65f1.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389783.png)

变量分为两种类型：

- **普通变量**

  点击编辑按钮可对普通变量进行批量编辑。

  ![1642647991016-ab28e191-c0b7-49df-ac78-3abce64c1469.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389784.png)

  新增变量时需填写**变量名、变量类型，变量描述**为可选填项。

  操作列按钮功能如下：

  ![1642647991411-43af27d6-bea2-4d94-a094-79115914ac20.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389785.png)

  - **设为私有变量**：设置为私有变量后，该变量的值将千人千面（不同用户看到的值不同），适用于点赞数等个性化场景。
  - **复制变量**：快捷新增一个变量的复制副本。
  - **删除变量：**移除该变量。
  - **编辑 Mock 数据**：为该变量设置模拟数据值。

  编辑完成后点击"保存"即可更新变量。
- **表达式变量**

  表达式变量是对多个普通变量的引用与计算。编辑方式与普通变量类似，重点在于**表达式内容**的填写。

  例如：假设有变量 `number` 值为 1，变量 `number2` 值为 2，则表达式 `${number} + ${number2}` 的结果为 3。

  ![1642647992060-b90d39a9-81be-4e1d-bcb8-bde9855ef10f.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1969562461/p389786.png)

  更多语法请点击文本框后的图标按钮查看。

#### **Mock 数据**

Mock 数据面板用于对所有普通变量进行数据模拟，变量在卡片中被引用时将使用其 Mock 值。

![1642647992685-a30f3bf4-950d-4f7e-8f46-5522d8ae8cde.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7065806871/p389787.png)

Mock 数据分为公有数据和私有数据：

- **公有数据**：对公有变量的数据模拟。
- **私有数据**：对私有变量的数据模拟（取决于该变量是否被标识为私有变量）。

## 编辑画板区

编辑画板区包含**顶部操作栏**和**编辑区域**：

### **画板操作栏**

操作栏共包含**预览模式的开关**以及**模拟器相关配置的设置**，如环境、版本号等。

![1642647993720-5ccd53a2-da48-4ea0-8e2e-0d7e000a1ab7.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389789.png)

- **预览模式**：依据当前 Mock 的数据对卡片进行实际渲染、组件条件渲染以及循环渲染，同时组件的点击事件也会生效。

  > **[!NOTE]**
  >
  > 预览模式下不可编辑。
- **模拟暗黑模式**：以暗黑模式样式渲染卡片，便于预览和调整暗黑主题效果。

  ![1642647994198-e88f0010-80aa-49c6-a337-f4276b694ce4.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389790.png)
- **模拟环境**：在**桌面端**、**安卓**或 **iOS** 环境间切换。
- **模拟版本号**：模拟不同钉钉版本号的显示效果。
- **模拟语言**：支持简体、繁体、英文、日文、越南文、泰文、印尼文七种语言的国际化测试。

### **编辑区**

编辑区用于对选中的卡片区域进行布局调整和组件编辑。

![1642647994654-672b9b5c-63ad-4855-a241-3c331f5772ad.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389791.png)

#### **布局调整**

选中组件后，长按并拖拽即可调整其在卡片中的位置，以进行快速布局。

![1642647995191-6e22bead-1dfe-4208-8cf1-37c781757b83.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389792.png)

#### **组件编辑**

选中组件后组件的右上角出现了一个操作栏。

![1642647995688-7128ed22-2d40-40dc-a6e0-f4d574888921.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389793.png)

从左到右分别是**祖先组件快速选择按钮**、**复制按钮**以及**删除按钮**。

- **祖先组件快速选择**：快速选中当前组件的某个祖先组件。例如基础文本组件的嵌套关系为"卡片→布局容器→布局→基础卡片"，可通过此功能快速定位上级组件。

  ![1642647996208-759411e0-c586-42dd-8671-f3e7257b99bf.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389794.png)
- **复制按钮**：在父组件下克隆当前组件。

  ![1642647996717-2b2a3be6-bab5-4dc9-92b3-27719a960df2.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389795.png)
- **删除按钮**：删除选中的组件。

选中组件后，右侧属性设置区将显示该组件的所有可配置属性，包括样式、内部布局、内容配置、数据源绑定等。

## 组件属性设置区

以基础文本组件为例，其属性设置区如下：

![1642647997303-5f84e515-cc86-428c-bb83-9c3492bc0cf4.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2969562461/p389796.png)

基础文本组件包含以下属性：内容、最大行数、图标、对齐方式、文字颜色、尺寸、行高等。

为便于理解，将属性分为两类：

### **静态属性**

静态属性的值固定不变。例如：

- "对齐方式"设为左对齐后，始终显示为左对齐。
- "文字颜色"设为橘黄色后，文本颜色恒定为橘黄色。
- 文字尺寸、行高等也属于静态属性。

### **混合属性**

混合属性既可以是静态值，也可以绑定变量实现动态变化。识别方式如下：

#### 形式一：文本输入框 + 变量占位符

![1642647997729-2e559463-1d6e-4170-80ad-b3100d7913db.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3969562461/p389797.png)

通过 `${variableName}` 占位符引用变量。例如：变量 `appName` 的 Mock 值为"阿里味"，输入 `我是${appName}` 后，卡片渲染结果为"我是阿里味"。

![1642647998372-26b1606e-8435-4e90-82b2-62adaf86bfb4.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7065806871/p389798.png)

如果要取循环数组里面的变量，则可以使用 `${loop.variableName}` 格式进行表达。

#### 形式二：固定值 / 绑定变量 单选

![1642647999015-2fcea506-7a45-441f-af0d-0b64aa7d39b5.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3969562461/p389799.png)

提供两个选项：

- **固定值**：直接输入具体数值，行为与静态属性相同（如左边距属性）。

  ![1642647999542-f06630d1-eaa2-4d82-9476-a004cb7b61ba.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3969562461/p389800.png)
- **绑定变量**：通过下拉框选择符合条件的变量（类型需匹配）。例如数字类型属性只能绑定数字类型变量。

  ![1642648000039-b4a32afc-4087-4af5-98aa-f75956a863ba.png ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3969562461/p389801.png)

综上，基础文本组件的"内容"、"最大行数"和"图标"属性均为混合属性。
