# 钉钉Deap平台使用MCP服务

本文详细介绍了如何在钉钉的Deap平台内直接使用钉钉MCP服务。

## **准备工作**

- 企业已经完成了开发者后台注册。
- [访问 MCP 广场](https://mcp.dingtalk.com/#/)选择服务，并确定好目标服务。
- 部分MCP服务需要申请权限。

## **操作步骤**

1. 访问[钉钉Deap平台](https://deap.dingtalk.com/)。
2. 通过 Deap新建或编辑智能体，并使用 MCP。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8299859671/p1049990.png)
3. 点击**添加技能**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8299859671/p1049991.png)
4. 点击**新建MCP服务**，创建新的MCP 服务。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8299859671/p1049993.png)
5. 填写名称、描述和HTTP URL，并点击**MCP检测**，效果如下图所示：

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8299859671/p1050034.png)

   MCP检测通过后，点击确定创建即可。
6. 最后点击右上角**发布**按钮，发布当前Agent。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8299859671/p1050036.png)

   发布成功后，即可进行体验，如下图所示：

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8299859671/p1050037.png)
