# 步骤一：成为产品方案商并上架应用

本文介绍了如何成为产品方案商并将第三方企业应用上架到钉钉应用市场。

参考以下步骤，成为产品方案商并上架应用：

1. 入驻成为产品方案商。

   在开发第三方企业应用前，你需要完成产品方案商的入驻，如何入驻产品方案商可参考[入驻成为产品方案商](../../01-应用开发/07-TjCzIgfQs3-平台服务/0028-become-an-application-service-provider.md)。
2. 完成应用开发和自检。

   完成应用开发后，你需要完成应用自检，应用的开发和自检可参考[完成应用开发和自检](../../01-应用开发/07-TjCzIgfQs3-平台服务/0029-application-development-and-self-inspection.md)。
3. 提交应用商品上架。

   完成应用的开发和自检后，可提交应用上架申请，完成应用上架，详情可参考[提交应用商品上架](../../01-应用开发/07-TjCzIgfQs3-平台服务/0030-submit-your-product-to-the-shelves.md)。

   > **[!NOTE]**
   >
   > 应用上架常见问题，可参考[应用上架常见问题](../../01-应用开发/07-TjCzIgfQs3-平台服务/0031-application-market-open-capability-access.md)。
