# 编辑自定义工作台

本文档介绍如何编辑自定义工作台，以PC端自定义工作台编辑为例，移动端类似。

## 视频演示

[](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20230404/nmnv/屏幕录制2023-03-31 下午3.59.29.mov)

更详细的搭建视频可查看 [5min搭建PC自定义工作台](https://h5.dingtalk.com/group-live-share/index.htm?type=2&liveFromType=6&liveUuid=21c2f3c8-0470-4b48-a508-3ea7aae32ac8&bizType=kankan&dd_nav_bgcolor=FF2C2D2F#/union)

## **编辑步骤**

1. 进入创建的工作台项目的PC详情。

   ![1108进入PC详情.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2255107871/p736079.png)
2. 在工作台项目PC详情页，如果是需要直接创建页面，可直接点击左侧“添加自定义工作台页面”。如果要编辑存量页面，可点击右上角编辑工作台按钮。

   ![1108编辑工作台.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2255107871/p736086.png)
3. 自定义工作台提供了丰富的行业模板，可一键启用，即开即用。对工作台需要更多定制能力的可以联系对应的模板提供服务商。

   ![1108模板中心.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2255107871/p736090.png)![1108行业模板服务商信息.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2255107871/p736171.png)
4. 需新增页面时，点击新建页面。

   ![iShot2022-12-21 10](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2255107871/p537173.png)
5. PC端工作台设计器左侧，拖拽需要的组件进入编辑区域。

   ![1108搭建自定义工作台.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2255107871/p736100.png)

   组件库提供**官方组件**、**自建组件**和**三方应用**三大组件类别。

   - 官方组件由钉钉官方提供，包括标准工作台中的核心业务组件及更多扩展组件，可通过拖拽直接使用。官方组件详见 [官方组件](0005-official-components-1.md)。
   - 自建组件由当前本企业设计发布，只允许当前企业使用的组件，在插件管理中开发全量后通过拖拽直接使用，包括低码组件和全码组件。例如在移动端工作台设置 - 组件设置中创建的数据组件、视频组件作为自建组件都可在此处直接使用。具体可参考本文档的组件教程。
   - 三方组件由客户或服务商通过钉钉开放平台小程序IDE自主研发并发布上架，客户购买对应应用后在设计器的该区域可见应用关联的三方组件，并通过拖拽使用。
6. 设计器画布区顶部还支持深色模式、移动桌面工作台编辑切换、模拟尺寸切换等。

   > **[!NOTE]**
   >
   > 移动端桌面端切换相当于从移动详情、PC详情页面进入对应设计器的快捷操作。如果切换后发现右上角按钮置灰，说明不在编辑状态，可重新从对应的移动详情/PC详情页面点击“编辑工作台”后进入即可。

   ![1108设计器工具栏.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2255107871/p736108.png)
7. 自定义工作台最新升级内容及贴心教程，可点击设计器右上角“小贴士”了解。

   ![1108小贴士.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2255107871/p736106.png)
8. 编辑完成后，点击右上角保存按钮。

   > **[!NOTE]**
   >
   > 更多工作台搭建及组件视频可前往 [开发者社区工作台开放](https://open.dingtalk.com/developer/topic) 查看工作台栏目。
