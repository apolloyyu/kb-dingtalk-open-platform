# 接入流程

本文介绍了钉钉门禁Linux SDK接入流程。

## 步骤一：创建门禁产品

设备厂商首先需要联系钉钉创建好门禁产品。厂商需要提供如下信息给钉钉。

| 提供的信息 | 说明 |
| --- | --- |
| 厂商的客服热线 | 显示在微应用。 |
| 支持人脸数 | 根据容量制订，显示在微应用。 |
| 设备logo图片 | 在微应用上显示。原始尺寸 56x56。 |
| 产品名称 | 中文名称和英文名称。 |
| 是否自行布署人脸算法服务器 | 是否布署算法服务，采用的SDK版本不一样。 |
| 是否使用钉钉微应用进行门禁的管理 |  |

钉钉生成PRODUCT\_ID、PRODUCT\_KEY、PRODUCT\_SECRET、PRODUCT\_SIGN，发放给接入厂商。
客户需要根据是否布署人脸算法以及是否使用钉钉微应用进行门禁管理选项，去下载不同的SDK版本。

## 步骤二：算法服务器部署

大部分客户是自己布署算法服务器的，这些门禁客户需要下载的是SDK中不包含阿里巴巴人脸算法的版本。

如魔点、华安由第三方提供人脸算法，三方需要在部署一台算法服务器，用来做抽取特征使用，特征抽取后通过SDK下发给三方应用。

布署算法服务器，需要遵循如下原则：

1. 按照下表接口开发算法服务，本地部署完成，自测通过。

   **同步人脸特征提取接口说明**

   **请求地址**：POST `http://ip/face/getFeature?versionlist=xxx,xxx,xxxpost%E5%86%85%E5%AE%B9base64Image=xxxxx`

   **请求参数**：

   - **ip**：特征提取服务器的IP地址
   - **versionlist**：提取特征的版本列表，字符串格式，每个特征版本信息以逗号分隔
   - **base64Image**：待提取特征的图片，base64编码格式（post内容）

   **返回结果**：

   返回结果示例如下。

   ```
   {
     "code":1, 
     "data":[
        {
           "version":"102",
           "feature":"xxx"
         },
        {
           "version":"201",
           "feature":"xxx"
         }]
   }
   ```

   - **code**：特征提取结果，整型格式，具体字段正在定义中。
   - **date**：返回的特征信息，json数组格式。
   - **version**：返回特征的版本信息，字符串格式。
   - **feature**：提取的特征信息，base64编码的字符串格式。
2. 在聚石塔或者钉钉云环境的**华北三**地址采购一台ECS服务器，部署算法服务。

   性能要求为不低于20QPS（每秒抽取20张人脸特征），部署完成，自测通过，提供测试报告到钉钉。

   > **[!IMPORTANT]**
   >
   > 算法服务必须保证开机自动重启。

   测试内容如下：

   | **测试项** | **预期** |
   | --- | --- |
   | 5W人脸图片不停的调用http接口抽取特征，循环抽取100W次，图片规格为400\*800像素 | 1. 每次都成功抽取 2. 服务不出现异常 |
   | 单台服务器在50 http并发请求的情况下的性能（QPS） | 无 |
   | 异常自我恢复 | 1. 崩溃后自我恢复 2. 异常检测自我恢复 |
   | 开机自启动服务 | 开机服务自启动 |
3. 接入方联系钉钉，提供ECS服务器规格，钉钉生成合同，双方签署合同。

   > **[!IMPORTANT]**
   >
   > - 至少要部署两台服务器（用户容灾备份）。
   > - 三方购买服务器时候为了满足性能需要一台高端设备时，请更换为多台低端设备，多台性能之和能满足性能要求即可。例如：满足20QPS需要一台8核设备，那建议更换为2台4核设备。
4. 钉钉购买ECS服务器，接入方共享镜像给钉钉（复制到华北3，联系钉钉进行分享），钉钉复制镜像到新购服务器。
5. 三方提供feature\_version，钉钉提供feature\_type，钉钉进行服务端部署。
6. 联系钉钉接口人，加入到钉钉万人测试组织，使用feature\_type、feature\_version进行5万人全量拉取特征测试，提供测试结果。

   测试内容如下：

   | **测试项** | **预期** |
   | --- | --- |
   | 抽取特征测试 | 全部图片可以抽取特征成功 |
   | 抽取性能测试 | 满足上述2中的性能要求 |
