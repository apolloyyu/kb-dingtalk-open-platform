# 创建自定义工作台

本文档介绍自定义工作台创建的流程。

## **操作流程**

1. 登录[开发者后台](https://open-dev.dingtalk.com/)，在开放能力中选择**工作台**。

   ![iShot2022-12-20 15](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1255107871/p536988.png)
2. 在工作台管理模块中，右侧点击“+设计器项目”。

   > **[!NOTE]**
   >
   > - 只有自定义工作台权益能看到该界面，详见 [常见问题-工作台权益已失效](0028-faq.md)。
   > - 若通过产品方案商开通工作台，客户不支持创建项目，可查看对应项目进行编辑。

   ![创建设计器搭建自定义工作台1108.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1255107871/p736056.png)
3. 填写自定义工作台名称和备注，并点击**创建**按钮即可生成。

   ![iShot2022-12-20 15](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1255107871/p536994.png)
4. 自定义工作台项目支持分端编辑，可单独进入移动详情或PC详情编辑，同时支持项目重命名、删除。

   > **[!NOTE]**
   >
   > 支持按工作台名称（即项目名称）进行模糊搜索，已启用的项目会默认展示在最前面，方便快速编辑调整。

   ![1108自定义工作台项目列表使用.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1255107871/p736063.png)
