# 微应用页面导航栏透明

通过dd\_nav\_translucent参数设置微应用页面导航栏透明。

## 使用说明

| **客户端** | **Android** | **iOS** | **PC** |
| --- | --- | --- | --- |
| 支持说明 | 支持 | 支持 | 不支持 |

在url后面拼接`dd_nav_translucent=true`参数，示例如下：

```
http://abc.xyz?dd_nav_translucent=true
```
