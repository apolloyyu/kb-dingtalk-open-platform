# 常见问题

## **如何创建宜搭应用？**

1. 打开钉钉客户端 > 工作台 > 宜搭。

   ![选择宜搭..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667619.png)
2. 创建宜搭应用。

   ![创建宜搭应用..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667621.png)

## **如何创建流程表单？**

1. 单击上述创建的宜搭应用。

   ![单击附件应用..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667629.png)
2. 单击**新建流程表单**。

   ![新建流程表单..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667630.png)
3. 选择**从空白表单新建**。

   ![新建表单..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667632.png)
4. 表单命名。

   ![附件表单..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667645.png)
5. 组件库选择。

   本示例选用一个单行文本组件和一个附件组件。

   - 单行文本：

     ![单行文本..gif](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9062823861/p667709.gif)

     > **[!NOTE]**
     >
     > 查看组件唯一标识：
     >
     > ![唯一标识宜搭..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667717.png)
   - 附件：

     ![附件宜搭..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667666.png)
6. 保存表单。

   ![保存表单宜搭..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667670.png)
7. 设置流程并进行保存和发布。

   ![保存并发布宜搭..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667683.png)

## 如何创建数据表单

1. 单击上述创建的宜搭应用。

   ![单击附件应用..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667629.png)
2. 单击**新建普通表单**。

   ![普通表单.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p697518.png)
3. 选择**从空白表单新建**。

   ![从空白表单创建.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p697516.png)
4. 根据实际需求，选择组件。

   ![组件选择.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p697523.png)

> **[!NOTE]**
>
> 查看组件唯一标识：
>
> ![唯一标识宜搭..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667717.png)

## **如何查询表单及应用参数？**

1. 单击宜搭应用。

   ![单击附件应用..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667629.png)
2. 单击**应用设置** > **部署运维。**

   ![应用参数宜搭..png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9221943871/p667694.png)
