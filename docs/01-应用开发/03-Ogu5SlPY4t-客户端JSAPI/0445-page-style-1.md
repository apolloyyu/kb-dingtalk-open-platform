# 页面样式

每个页面中的根元素为 page，需要设置高度或者背景色时，可以使用这个元素。

```
page {
  background-color: #fff;
}
```

更多详细信息请参考[ACSS样式语法参考](https://open.dingtalk.com/document/dingstart/mini-app-acss-style-syntax-reference)。
