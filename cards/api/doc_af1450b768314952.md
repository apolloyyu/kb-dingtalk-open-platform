# 查询企业看鉴 BV 设备详情

doc_id: doc_af1450b768314952
completeness: full
archived: false
method: GET
endpoint: https://api.dingtalk.com/v1.0/dvi/bv/kanjian/devices/detail
api_version: v2-new
app_types: 企业内部应用
permissions: Dvi.KanJian.Device.Read

## Request headers
- x-acs-dingtalk-access-token (String, required): 调用该接口的访问凭证，通过调用获取企业内部应用的accessToken接口获取。

## Path params
- none

## Query params
- deviceSn (String, required): 设备序列号，须为本企业生效绑定的设备，可通过分页查询看鉴 BV 设备列表接口获取。

## Body
- none

## Returns
- optional: result(Object), batteryLevel(Long), bindStatus(String), chargeStatus(Boolean), coverStatus(String), deviceName(String), deviceSn(String), firmwareVersion(String), onlineStatus(String), recordingStartTimeMs(Long), signalStrength(Long), storageFreeMb(Long), storageTotalMb(Long), workStatus(String)

## Limits
- none stated
