# 概述

本文介绍什么是数字区县，如何开通数字区县，以及数字区县接口能力。

## 什么是数字区县

数字区县是一种解决方案，助力区县政府数字型基础建设，全面提升区县基层组织的治理能力，实现乡村振兴。

![iShot2022-01-14 17](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3814512461/p384958.png)

## 如何开通数字区县

查看[数字区县解决方案](https://page.dingtalk.com/wow/dingtalk/act/szxy?spm=a213l2.13146415.4929779444.72.39671d5aAMOhHV)了解如何开通数字区县，可以根据实际需求提交申请。

## 开放概览

数字区县提供了丰富的接口开放能力，开发者通过API接口可以实现数字区县和企业业务系统打通。

| API | API说明 | API版本 |
| --- | --- | --- |
| [增加或减少居民积分](1095-increase-or-decrease-resident-points.md) | 在积分管理或者全员圈场景中，可调用本接口添加居民积分。 | 新版 |
| [查询组织维度配置的所有积分规则](1096-query-all-credit-rules.md) | 在全员圈和积分管理场景下，可调用本接口查询组织维度配置的的积分规则。 | 新版 |
| [分页查询居民积分流水](1097-query-the-integral-flow-records-by-page.md) | 在全员圈或积分管理场景下，可调用本接口分页查询积分流水。 | 新版 |
