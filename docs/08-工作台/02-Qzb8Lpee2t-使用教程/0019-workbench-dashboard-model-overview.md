# 概述

本文介绍了第三方企业应用组件（即第三方全码组件）的基本概念及组件与应用、人群、解决方案之间的关系。

## 简介

第三方企业应用组件有一个完整的业务功能，包含视图和逻辑，可在工作台中使用。

组件分为以下两种状态：

- **未授权态**：在客户未开通应用或者解决方案前，在客户的工作台上通过预置展示的组件的状态。客户通过点击组件即可进入应用或者解决方案页面，在页面内完成授权和启用。
- **已授权态**：组件归属的应用或者解决方案已授权客户使用，在客户工作台上展示的组件的状态。

第三方企业应用可以通过组件将应用关联的内容显示在工作台，实现数据和操作的浅透出，如下图所示：

## 组件与应用的关系

- 一个应用可拥有多个组件。
- 一个组件只能归属于一个应用。
- 一个组件可以归属于多个解决方案。
- 组件的授权范围最大值为应用的授权范围。
- 组件的生命周期与应用的生命周期保持一致。
- 客户在实际使用应用时可以选择应用中单个或者多个组件添加到工作台使用。

## 组件与人群的关系

一个应用可对应多个组件，每个组件可以设置不同的人员使用，比如“客户管理”应用，至少会支持以下用户角色使用：

- 销售专员
- 销售总监
- 财务
- 老板

针对这种情况，同一个应用可以创建多个组件，每个组件针对一个或多个角色设计展示内容和功能。客户在安装组件时，可以设置不同组件的人员范围，工作台将根据可见范围设置来对不同人员展示不同的组件。

## 组件和解决方案的关系

> **[!NOTE]**
>
> 组件如何接入解决方案，请参见[组件接入解决方案](0021-component-access-solutions.md)。

- 组件可以单独使用，也可以多个应用的不同组件，组合成一个解决方案。
- 解决方案由钉钉开放平台小二根据用户使用习惯进行包装，例如财务解决方案、人事解决方案等，将在组件中心页面展示。
- 在解决方案的场景下，平台支持批量开通应用、组件和设置多组件的可见范围。

  > **[!NOTE]**
  >
  > 组件的可见范围与应用的授权范围是保持一致的。
