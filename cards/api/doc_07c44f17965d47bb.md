## Request headers
- x-acs-dingtalk-access-token (String, required): 调用该接口的访问凭证，通过调用获取企业内部应用的accessToken接口获取。

## Path params
- none

## Query params
- taskId (String, required): 主任务 ID，可通过分页查询看鉴任务列表接口获取。

- none

## Returns
- optional: result(Object), creatorUserId(String), description(String), gmtCreation(Long), gmtModification(Long), subTasks(Array), instruction(String), name(String), options(Array of String), taskId(String), type(String), reportContent(String), status(String), adminUserIds(Array of String), executorUserIds(Array of String)
