# 获取自定义机器人 Webhook 地址

自定义机器人发送消息，需要获取机器人的 Webhook 地址，你可以参考本文档操作步骤获取机器人机器人Webhook。

## **前提条件**

完成[创建自定义机器人](0081-custom-bot-creation-and-installation.md)流程。

## **操作步骤**

1. 登录钉钉客户端，进入目标群聊会话。
2. 单击右上角**群设置**标识。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5250174871/p768501.png)
3. 单击**群管理**> **机器人**，选择已创建的自定义机器人。
4. 获取 Webhook 地址。

   > **[!IMPORTANT]**
   >
   > 请保管好此 Webhook 地址，不要公布在外部网站上，泄露有安全风险。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5250174871/p768502.png)

## **后续步骤**

如果你需要根据 Webhook 地址发送消息，可以参考[自定义机器人发送群聊消息](../02-4a8AMF6u2A-服务端-API/0702-custom-bot-to-send-group-chat-messages.md)。
