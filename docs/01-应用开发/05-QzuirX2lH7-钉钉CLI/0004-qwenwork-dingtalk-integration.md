# 在千问办公中接入钉钉

## **什么是千问办公**

千问办公（QwenWork）是阿里巴巴推出的一站式 AI 办公平台，以对话交互为核心，支持数据分析、PPT生成、视频剪辑、网页搭建等复杂任务的直接交付。用户仅需一句话描述需求，即可获得可交付成果。平台现已覆盖[桌面端](https://qwenwork.cn/docs/getting-started/desktop-workflow)与[网页端](https://qwenwork.cn/docs/getting-started/basic-workflow)，并深度接入钉钉生态，通过个人云盘、IM、连接器等模块打通数据与设备，使 AI 融入日常工作流。

![QwenWork 产品界面](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1558766871/p1094932.png)

千问办公基于前沿大模型为基座，凝聚核心技术能力，让千问办公真正做到对话即交付。

## **什么是钉钉连接器**

千问办公默认通过对话协助用户完成任务。但在实际工作场景中，用户还需访问网页、查阅日历、处理邮件，或在企业协作中使用钉钉等平台。连接器是千问办公与外部系统之间的桥梁：启用后，AI 可操作浏览器、读写系统日历与邮件、对接 Microsoft 365，也可通过钉钉以自然语言完成待办创建、日报撰写、读取并总结钉钉消息、撰写钉钉文档等常用流程。

![QwenWork 产品界面](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1558766871/p1094928.webp)

## **如何使用钉钉连接器**

### **登录钉钉账号**

1. 在千问办公平台的**连接器**模块中，选择**钉钉**。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1558766871/p1094933.png)
2. 在弹窗中，点击**安装**。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1558766871/p1094937.png)
3. 点击**安装**后，在下一步点击**立即登录**，并选择所属组织完成登录。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1558766871/p1094930.png)
4. 当显示“已连接到钉钉”时，表示连接成功，最后点击**启用**即可。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1558766871/p1094939.png)

### **开始尝试你的第一个任务**

在千问办公平台的**新任务**模块中，开始尝试你的第一个任务。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1558766871/p1094931.png)
