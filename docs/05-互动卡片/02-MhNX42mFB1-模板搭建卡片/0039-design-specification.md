# 设计规范

本文介绍互动卡片在不同场域下（IM、吊顶、工作台等）的设计规范，同时提供了相关设计资源的下载入口。

## **概述**

钉钉互动卡片拥有统一的设计规范，是我们基于大量的卡片应用整理和总结出来的卡片设计的最佳实践，保障了各个场景下钉钉互动卡片体验的标准性和一致性。所有互动卡片的搭建都应参照[互动卡片设计规范](https://ding.design/#/cate/1/page/785)进行搭建，否则有可能影响酷应用的发布与上架。
