# 大屏模板使用

## **概述**

平台预置了一系列大屏模板样例，这些内置模板具有统一的色彩风格、预置的静态数据、完备的功能以及特定的应用场景基础。用户可以基于这些模板，快速引入企业自有数据，轻松打造与企业需求相符的数据可视化大屏。

> **[!NOTE]**
>
> 当前功能属于**高级版**。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8770954371/p890574.png)

### **搭建流程**

1. 单击“更多模板”。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8770954371/p890576.png)
2. 选择心仪的模板创建并命名。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8770954371/p890577.png)
3. 根据需求调整大屏的数据源（具体见[数据源配置](../01-fIz0pQ6X4y-平台介绍/0015-interactive-large-screen-data-source-configuration.md)）及大屏样式。
