# 基础信息配置

> **[!NOTE]**
>
> **免费版**、**高级版**均可使用。

## **概述**

基础信息配置用于引导用户快速了解并使用问数助理，核心包含两类设置：

- **助理基础信息**：自定义头像、名称、描述，塑造助理的IP形象。
- **欢迎语和开场白**：通过一段文字介绍助理的功能定位，并配置推荐指令降低用户上手门槛。

**核心价值**：显著降低用户使用问数助理的学习成本，让用户首次对话就能明确助理的能力边界和使用方式。

## **搭建流程**

以搭建一个"IPD产品研发分析助理"，实现数据智能分析为例，展示基础信息配置的实际效果：

### **配置目标**

让用户第一次使用时就能快速了解该助理专注于IPD（集成产品开发）流程的数据分析，并能立即开始提问。

### **配置步骤**

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2770954371/p890509.png)

1. **配置助理基础信息**

   1. 传与IPD主题相关的专业头像；
   2. 设置名称为"IPD研发分析助理"；
   3. 填写描述："专注IPD流程数据分析，支持研发进度、质量指标、资源投入等多维度查询"。
2. **配置欢迎语**

   撰写一段友好的欢迎文案，例如："你好！我是IPD研发分析助理，可以帮你查询研发项目进度、分析质量趋势、统计资源投入等。试试问我'当前有哪些延期项目？'"。
3. **配置开场白**

   设置3条以内的推荐指令，每条不超过30个字。

### **使用效果**

用户第一次使用的时候可以快速了解该助理的职能范围，并快速上手使用。
