# 概述

本文档介绍了MCP 服务和MCP 广场是什么、能力概览及如何接入MCP服务，帮助开发者能快速实现能力对接。

## **什么是MCP 服务**

MCP（Model Context Protocol）是一种给大模型使用的连接协议，但对企业用户而言，真正使用的是基于该协议封装好的 MCP 服务，即一个个标准化、可被大模型直接调用的“技能”。

你可以把每个 MCP 服务理解为：

- 一个预集成好的工具包（比如“合同风险审核”“会议语音转写”“发票信息抽取”）；
- 一个安全可控的能力单元，企业只需授权，大模型就能在合规范围内调用；
- 一种无需开发即可接入的 AI 能力，直接用于 AI Agent、自动化工作流或智能应用中。

目前，钉钉**已提供 6000+ 企业级 MCP 服务**，是中国规模最大的企业级 AI 技能市场。

## **钉钉提供哪些MCP 服务**

钉钉 6000+ MCP 服务来自两个核心供给方，覆盖从基础办公到专业行业的全场景需求：

### **钉钉官方产品能力封装**

钉钉将自身高频使用的办公协同能力，直接转化为 AI 可调用的服务，通常不额外消耗企业算粒：钉钉文档 AI、AI 表格、钉钉会议、日程、待办、审批等流程操作等，这些构成了钉钉企业 AI 应用的基础能力底座。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2400959671/p1049985.png)

### **生态能力汇聚于“钉钉 MCP 广场”**

MCP 服务广场是钉钉“AI 能力中台”的对外服务门户，提供**标准化、即插即用的 AI 能力集合**。所有能力均封装为 MCP 服务，支持开发者通过低代码或 API 灵活集成，快速构建智能客服、自动化流程、行业解决方案等应用。

可点击链接[访问 MCP 广场](https://mcp.dingtalk.com/#/)。

![钉钉MCP广场](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2597049671/p1049044.png)

MCP广场重点引入高价值能力，所有能力均以 **标准 MCP 服务** 形式提供，覆盖以下关键场景：

| 能力类别 | 核心价值 | 典型能力示例 |
| --- | --- | --- |
| 多模态 AIGC | 图文音视频智能生成，提升内容创作效率 | 文生图、图生视频、语音合成（TTS）、文本续写与润色 |
| 智能信息处理 | 高效解析非结构化数据，提升信息处理速度 | OCR文字识别、语音转写（ASR）、语义理解、情感分析、文档关键信息抽取 |
| 行业垂直能力 | 深度融合行业知识，解决特定业务问题 | 法律文书生成、合同智能比对审核、教育场景智能批改、金融领域风险识别 |
| 实用工具增强能力 | 无缝集成日常办公场景，扩展 AI Agent 能力 | 浏览器自动化操作、火车票/机票查询预订、企业信息查询、实名认证 |
| 文档自动化处理 | 降低文档处理成本，提升办公效率 | PDF/Word文件解析、公章/印章识别、手写签名识别、文件格式转换 |

## **差异化优势**

钉钉不只是“接入了 MCP 服务”，而是将 MCP 打造成一个真正适合企业规模化、安全、低成本、易管理使用的 AI 能力市场。通过“平台级整合交付”模式，钉钉 MCP 广场帮助企业快速发现、零门槛试用、统一治理、按需付费、跨部门协同，真正推动 AI 从试点走向规模化落地。

**传统 MCP 广场** vs **钉钉 MCP 服务广场** 对比：

| **对比** | **传统 MCP 模式** | **钉钉 MCP 服务广场** |
| --- | --- | --- |
| 接入方式 | 每个服务商需单独注册账号、申请 API Key、手动配置，流程繁琐、门槛高 | **一键开启，**无需管理多套账号密钥；全部远程能力可在钉钉内直接调用，无缝集成 |
| 计量计费 | 各服务商独立计费，对账复杂；预付费为主，效果不佳也无法退款 | **统一按实际调用量计费**（按时用计费），避免资源浪费；**算粒统一扣减**，成本透明、对账简单 |
| 体验门槛 | 通常需先付费或签约才能试用，试错成本高 | 支持所有钉钉组织免费试用，组织每周赠送体验额度；部分付费服务还额外赠送免费额度 |
| 预算管理 | 各部门各自采购，预算分散，难以统筹 | 支持公司**统一预算采购（AI 算粒包）**，采购后可分配算粒额度，实现跨部门预算统筹与灵活调配 |
| 治理能力 | 权限、审计、安全策略分散在各服务商平台，管理困难 | **统一权限管理：**无需跳出钉钉，统一授权、用量控制、操作审计；企业级安全治理 |

基于以上， 钉钉MCP 服务广场具备以下优势：

- **更敢用**：免费试用 + 体验额度，降低试错风险；
- **用得起**：按实际调用量付费 + 统一算粒结算，避免浪费；
- **用得久**：统一预算分配 + 跨部门协同，支撑长期规模化应用；
- **管得住**：平台级权限、审计与安全策略，满足企业合规要求。

## **集成方式**

MCP 服务支持 **双路径接入**方式，满足不同开发场景：

- 钉钉内集成  
  直接在 Deap 技能中心 或 自动化工作流 中调用，无需额外开发。

  示例：在审批流程中嵌入智能问答能力，如何操作可查看[钉钉Deap平台使用MCP服务](0008-dingtalk-deap-platform-using-mcp-services.md)文档。
- 外部系统集成  
  通过 标准 RESTful API 集成至自研系统或第三方 Agent 平台，支持跨平台调用。  
  示例：在阿里云百炼中使用MCP服务，如何操作可查看[阿里云百炼使用钉钉MCP服务](0009-alibaba-cloud-uses-dingtalk-mcp-services.md)文档。
