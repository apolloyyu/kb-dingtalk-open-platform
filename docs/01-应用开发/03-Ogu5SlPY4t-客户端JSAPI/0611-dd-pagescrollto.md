# 滚动到页面的目标位置

调用dd.pageScrollTo滚动到页面的目标位置。

## 扫码体验

![1595561094966-34](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2179903061/p174107.png)

## **示例代码**

```
dd.pageScrollTo({
  scrollTop: 100
})
```

## **入参**

| **参数** | **类型** | **说明** |
| --- | --- | --- |
| scrollTop | Number | 滚动到页面的目标位置，单位 px。 |
