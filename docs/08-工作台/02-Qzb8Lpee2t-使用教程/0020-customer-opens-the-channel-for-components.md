# 组件开通渠道

本文介绍了客户开通组件的不同渠道。

## 通过应用市场开通

在应用市场中，选择应用进入详情，完成授权时，会引导客户选择角色使用成员，实现组件在工作台首页的透出。

![市场](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2198787261/p300282.png)

## **应用点击推荐用户开通**

当系统发现用户在工作台有应用点击的行为，就会在不同场域出现推荐营销位，提醒用户把应用对应的组件添加到对应的场域。

![](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/LAJdl6KRGpEmnke1/img/d2d90cc2-5f59-42ff-96be-f8eab207f1df.png)

## 通过组件运营态开通

![分组](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2198787261/p300283.png)

## 通过组件中心开通

工作台底部会常驻组件中心功能，该功能可开通解决方案和组件。

![组件中心](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2198787261/p300284.png)

## 组件直接预装到工作台

平台方小二会将精选组件直接预装到客户组织工作台，客户通过工作台首页即可开启应用使用。

![预装](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2198787261/p300286.png)
