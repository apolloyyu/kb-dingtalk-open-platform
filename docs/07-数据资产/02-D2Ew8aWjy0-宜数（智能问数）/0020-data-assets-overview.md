# 概述

平台提供钉钉官方数据资产能力，具体为企业及其员工在使用钉钉官方应用过程中，沉淀并逐步形成的各类高质量数据资产，其使用行为包括但不限于企业内的应用开通、产品登录、产品使用等各方面。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0245754371/p889089.png)

## **资产特色**

- **全域**

  平台数据资产覆盖钉钉全域官方应用，包括办公数字化、组织数字化、业务数字化等各类应用。
- **高质量**

  平台数据资产不是原始的用户操作行为日志数据，是经过清洗、加工、转换后的，正确的、完整的、全局一致的数据体系。
- **多粒度**

  平台提供组织（按企业全局视角的）、组织部门（按企业各级部门视角的）、组织用户（按企业员工视角的）等多种维度的统计数据，以及各类业务明细数据，支持企业开箱即用或者二次加工使用。
- **实时+离线**

  平台提供实时和离线两类数据资产，满足企业不同数据消费场景对数据更新频率的差异化诉求，其中实时数据资产秒级延迟、离线数据资产次日（T+1）更新。
- **安全合规**

  平台提供的数据资产，符合国家数据安全相关法律法规要求，是归属于企业自身的数据，不包含归属于员工个人的数据。

### **资产属性**

- 数据项：平台数据资产的原子组成单位，具体表现为一个数据字段；
- 字段类型：字段的数据类型，包括字符型、数值型、日期型等多种；
- 更新频率：数据项的更新时效性，包括实时、离线T+1等两种；
- 统计维度：针对统计数据项区分统计维度，包括组织、部门、员工等三种，分别对应按企业全局视角统计、按企业各级部门视角统计、按企业员工视角统计；
- 统计周期：针对统计数据项分区统计周期，是指指标的统计时间范围长度，包括日、周、月、年等多种，分别对应按天统计、按自然周统计、按自然月统计、按自然年统计；
- 资产类型：区分统计指标、明细数据两种；
- 数据来源：数据来源的官方应用；
- 数据等级：根据数据价值密度，划分L1-L5等五个档次，档次越高，价值密度越高；
- 数据口径：描述数据项的业务逻辑和计算逻辑。
