# 数据权限配置

> **[!NOTE]**
>
> **免费版**、**高级版**均可使用。

## **权限说明**

智能问数权限支持配置**行级权限**和**列级权限**。

### **行级权限**

- **定义**：行级权限控制用户可以访问哪些行的数据。当需要限制某些字段值的查看范围时，你可以通过条件组合的方式设置行级权限，缩小字段值的可见范围。
- **通俗解释**：想象一张表是一个超市的账本，每一行代表一个交易记录。行级权限就像是在告诉某个员工：“你只能看属于你负责区域的账单，其他区域的账单你看不到。”
- **举例**：销售经理只能查看自己负责的省份（如“江苏省”）的销售记录，其他省份的数据对他是不可见的。在表中，会通过类似 WHERE dealer\_province = '江苏省' 的条件，限制数据访问。

### **列级权限**

- **定义**：列级权限控制用户可以访问哪些列的数据。当某些字段不能透出给用户时，你可以通过配置数据集的列级权限，对部分字段设置禁止查看。
- **通俗解释**：想象一张表是一个超市的账本，每一列代表一种信息，比如日期、金额、顾客名字等。列级权限就像是在告诉某个员工：“你只能看账单的日期和金额，顾客名字这些信息不能让你看到。”
- **举例**：财务部门的员工只能看到销售金额（sale\_total），但不能查看顾客姓名（dealer\_name）和商品明细（sku）。

## **适用范围**

- 有研发能力的大型、中小型企业。
- 有一定数据分析和数据开发背景的人。
- 对数据权限系统有一定了解的人。

## **场景一：**配置行级权限实现数据隔离

### **使用效果**

| **Before** | **After** |
| --- | --- |
| 某浙江省的销售经理，想查看广东省的销售情况，可以正常查询到，不符合预期 ❌  image | 浙江省的销售经理，想查看广东省的销售情况，提示无权限，仅允许访问浙江省的数据 ✅  image |

### **配置流程**

1. 配置[数据源](0005-data-management-configuration.md)，进入智能问数配置页面。
2. 单击权限配置 > 用户组 > 添加用户组，配置如下：

   > **[!NOTE]**
   >
   > 用户组适合对于一批用户，需要多次添加权限规则的场景，可以避免重复圈选。

   | **配置项** | **说明** |
   | --- | --- |
   | 用户组名称 | 填写用户组名称，例如：浙江省权限组。 |
   | 包含用户范围 | 选择对应的员工和部门。 |

   配置完成后，单击确定。
3. 配置完成后，单击侧边栏**数据管理**，找到对应的数据表。，单击 🔒 标识，进入行列级权限配置页面。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0180766871/p889677.png)
4. 在行列级权限配置页面，单击行权限 > 添加权限规则，配置权限内容：

   | **配置项** | **说明** |
   | --- | --- |
   | 规则名称 | 填写规则名称，区分不同规则项，例如：浙江省经理行级权限控制。 |
   | 用户范围 | 选择对应数据可读的用户范围，例如：选择上述创建的用户组。 |
   | 限定可查看的数据范围 | 设置数据范围条件。  image |

   配置完成后单击确认。
5. 设置其他用户的查看范围。

   > **[!NOTE]**
   >
   > 添加行级权限的时候，未被规则命中的用户，默认是拥有所有数据查看权限。如果仅希望配置了行级权限规则的人可访问数据，可以切换到其他未被规则命中的用户【无任何数据查看权限】。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0180766871/p889691.png)
6. 行权限配置完成后，你可以在预览调试台，再次测试验证效果。
