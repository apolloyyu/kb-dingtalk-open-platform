# 交互组件

本文介绍互动卡片所有支持交互的组件列表，以及交互的优先级。

## **支持交互的组件**

| **组件** | | **交互方式** |
| --- | --- | --- |
| 卡片 | | 通用交互方式（详见[交互方式](0031-interactive-mode.md)）。 |
| 基础组件 | 链接 | 通用交互方式（详见[交互方式](0031-interactive-mode.md)）。 |
| 横排/竖排按钮 | 通用交互方式（详见[交互方式](0031-interactive-mode.md)）。 |
| 布局/布局容器 | 通用交互方式（详见[交互方式](0031-interactive-mode.md)）。 |
| 图表 | 点击打开图表详情页（可配置是否启用）。 |
| 图片/多图 | 点击打开钉钉图片预览窗口（可配置是否启用）。 |
| 视频 | 点击打开独立播放器或在卡片内播放（可配置内播能力）。 |
| 轮播图 | 点击打开钉钉图片预览窗口（可配置是否启用）。 |
| 选择框 | 更新本地变量或发送回传请求。 |
| 区块组件 | 按钮 | 通用交互方式。 |
| 图片/多图 | 点击打开钉钉图片预览窗口（可配置是否启用）。 |
| 视频 | 点击打开独立播放器（暂不支持关闭）。 |
| 轮播图 | 点击打开钉钉图片预览窗口（可配置是否启用）。 |
| 时间选择器/文本+时间选择器 | 点击之后打开时间选择器控件。 |
| 聚合菜单/文本+聚合菜单 | 点击之后打开弹出聚合菜单。 |
| 多选下拉框/文本+多选下拉框 | 点击之后打开多选下拉框。 |
| 下拉框/文本+下拉框 | 点击之后打开单选下拉框。 |

## **不支持交互的组件添加交互**

从上方表格可以了解到，部分组件本身不支持交互，如果希望在不支持的组件中添加交互能力，就可以通过布局嵌套实现：将目标组件放置在"布局容器"内，由布局容器提供交互能力。

如下图，希望点击每篇文章时打开链接，可将文章标题和图片放置在布局容器内，并为布局容器设置点击事件。

## **交互优先级**

卡片通过布局容器嵌套时，同一位置可能存在多个交互逻辑，交互重叠时，卡片会按照一定的优先级来执行交互逻辑：**子节点交互优先级高于父节点，仅响应最深的子节点，其余父节点交互逻辑不执行。**

以上图为例，若布局容器设置了链接跳转，同时容器内的图片设置了预览功能：

- **点击图片区域**：触发图片预览（子节点优先级更高），不会发生链接跳转。
- **点击图片左侧文字**：触发链接跳转（文字无子节点交互，执行父节点逻辑）。

**核心原因**：图片的交互逻辑（子节点）优先级高于布局容器的交互逻辑（父节点）。
