# 接入流程

钉钉提供了线上问题监控及发布监控。应用测试完成后，即可接入钉钉的监控中心进行监控。

## 小程序接入

1. 登录[开发者后台](https://open-dev.dingtalk.com/)，进入目标应用。
2. 在**成员管理**内，单击**添加角色**添加对应的业务负责人。

   ![监控中心](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0294349871/p254049.png)
3. 添加成功后，进入监控中心，然后单击**查看监控大盘**，即可以看到监控。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0294349871/p1100364.png)

   ![查看监控大盘](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2129017161/p254053.png)

## H5微应用

1. 登录[开发者后台](https://open-dev.dingtalk.com/)。
2. 在**成员管理**内，单击**添加角色**添加对应的业务负责人。

   ![监控中心](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0294349871/p254049.png)
3. 选择**监控中心**，并单击**加入监控**。

   ![接入监控](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0294349871/p254059.png)
4. 添加成功后，单击**查看监控大盘**，即可以看到监控。

   ![页面访问监控](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4931846161/p254066.png)
