# 加工数据集

> **[!NOTE]**
>
> **高级版**可使用。

## **概述**

在现有数据集字段不满足要求时，可以通过数据工厂提供的数据加工能力，进行多表关联，新增衍生字段，数据过滤等操作来加工数据字段，满足业务需求。

## **功能价值**

通过数据加工，可以实现多表关联，新增衍生字段，数据过滤，并支持与官方数据进行融合分析，满足多样化的数据消费场景。

## **场景一：关联维表进行统计分析**

在很多数据处理的场景中，都有事实表与维表关联进行统计分析的需求，通过数据工厂，可以实现多张表的关联。

如某销售报表分析场景，需要将销售订单表与 商品维表和客户维表进行关联分析：

1. 创建数据准备类型的数据集，具体步骤详见[创建数据集](0016-create-a-data-set.md)。
2. 将销售事实表 与 商品维表 、客户维表拖入面板区
3. 单击“关联”按钮，配置关联关系。下方会自动跳转至配置关联关系页面，共有三个TAB。

   - **配置关联关系**：配置表之间的关联关系，选择“关联类型”（目前支持左关联及后关联），配置关联字段，系统默认展示一个关联字段，如需多个关联字段，单击下方添加按钮，增加关联字段即可。
   - **预览字段**：预览关联表的字段信息
   - **预览数据**：预览关联表的数据

## **场景二：新增衍生字段扩展数据集字段**

如在销售问数助理中，业务系统中的订单状态字段为0，1，3的数据值字段，在智能问数场景下对大模型不友好，可以通过新增衍生字段，将数据值字段 映射为中文名称字段，便于大模型理解，提高大模型问题识别率及准确率。

1. 单击右上角的“配置数据集”按钮，下方面板区会出现“新增衍生字段”按钮，单击“新增衍生字段”，进入衍生字段配置区

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6180766871/p889037.png)
2. 配置衍生字段

   - 填写字段名称，字段类型及字段描述，
   - 选择函数及字段，如将数值型订单状态转换成文本型字段，通过CASEWHEN 函数，对订单状态进行处理

   ```
   CASEWHEN(订单状态=0,'未支付',订单状态=1,'已支付',订单状态=2,'未发货',订单状态=3,'已发货','未知')
   ```

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6180766871/p889038.png)

   目前支持的函数列表：

   | **函数分类** | **函数名称** | **示例** |
   | --- | --- | --- |
   | **文本类** | LEN | LEN('text'),返回结果4；LEN('中'),返回结果3. |
   | CONCAT | CONCAT(字段1,字段2,字段3) 返回值为 123;字段1,2,3的值为'1','2','3' |
   | SUBSTRING | SUBSTRING(字段,2,1) 字段为ABCDEFG,返回值为B |
   | UPPER | UPPER(字段) 字段为ab,返回值为AB |
   | LOWER | LOWER(字段) 字段为aB,返回值为ab |
   | REPLACE | REPLACE(字段, a, b) 字段为abc,返回值为bbc |
   | TRIM | TRIM(<字段>) 字段为 b ,返回值为b |
   | COALESCE | COALESCE(<字段>, 1) 字段为null,返回值为1 |
   | **日期类** | CURRENT\_DATE | CURRENT\_DATE() 返回值为2024-08-20 |
   | CURRENT\_TIME | COALESCE() 返回值为10:36:22 |
   | QUARTER | QUARTER(<字段>) 字段为2024-08-20,返回值为3 |
   | YEAR | YEAR(<字段>) 字段为2024-08-20,返回值为2024 |
   | MONTH | MONTH(<字段>) 字段为2024-08-20,返回值为8 |
   | WEEK | WEEK(<字段>) 字段为2024-08-20,返回值为33 |
   | DAYOFYEAR | DAYOFYEAR(<字段>) 字段为2024-08-20,返回值为233 |
   | DAYOFMONTH | DAYOFMONTH(<字段>) 字段为2024-08-20,返回值为20 |
   | HOUR | HOUR(<字段>) 字段为10:36:22,返回值为10 |
   | MINUTE | MINUTE(<字段>) 字段为10:36:22,返回值为36 |
   | SECOND | SECOND(<字段>) 字段为10:36:22,返回值为33 |
   | **数据类** | CEIL | CEIL(字段1) 字段1为1.15,返回值为2 |
   | ROUND | ROUND(字段,1) 字段为1.15,返回值为1.2 |
   | FLOOR | FLOOR(字段) 字段为1.5,返回值为1 |
   | **逻辑类** | CASEWHEN | CASEWHEN(a.score<=60, '差', a.score>60 and a.score <=85, '良', a.score>85, '优秀'),score为90,返回结果:优秀 |

## **场景三：数据过滤获取所需数据**

如需要对数据集进行筛选，可以通过数据过滤能力，对数据进行筛选过滤。如需要筛选出已支付的物品单价大于100元的订单信息。

1. 单击右上角的“配置数据集”按钮，下方面板区会出现“配置数据过滤”按钮，单击“配置数据过滤”，会弹出配置数据过滤面板
2. 配置过滤条件，如需要筛选出已支付的金额大于100元的订单信息，需要配置两个且条件即可。

新增两个过滤：

- 订单状态=1
- 物品单价大于100
