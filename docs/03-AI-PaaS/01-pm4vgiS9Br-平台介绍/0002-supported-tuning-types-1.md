## **已支持调优类型**

### **GRPO 强化学习**

GRPO 是 DeepSeek 开创性的 [R1论文](https://arxiv.org/pdf/2501.12948)中引入的一种创新 RL 方法。与传统的 RL方法不同，这些方法需要收集标记的偏好数据来训练奖励模型，而 GRPO 可以使用可编程奖励函数直接优化模型行为。这允许模型开发解决任务的通用策略，而无需任何（或广泛的）人工反馈数据收集。

**GRPO强化学习的优点**

1. **免偏好数据**：无需人工标注的偏好数据集，直接通过编程式奖励函数优化模型
2. **双模型机制**：冻结的参考模型保持稳定性 + 可训练策略模型动态优化
3. **LoRA高效调优**：采用高秩LoRA适配器，仅训练0.1%参数实现全模型能力释放
4. **多任务兼容**：已验证支持DeepSeek R1/Qwen3/Llama3等不同架构模型

### **SFT 监督微调**

监督微调 （SFT） 侧重于指令调整，其中模型专门针对完成（输出）进行训练，以提高其指令跟随能力。此方法通过学习提示--完成对的高质量示例，使模型能够生成对用户提示的适当响应。SFT 对于增强模型理解和执行特定指令的能力特别有效，使其对于面向任务的应用程序更有用。

## **常见问题**

- **Q：哪些因素会影响训练时间和成本？**

  模型微调默认在 H20 GPU 上运行。训练时间主要取决于：

  - 数据集大小 ：您使用的数据集越大，训练所需的时间就越长。在尝试微调时，我们建议从较小的数据集（几百个示例）开始。如果结果看起来效果还不错，那么您可以使用完整的数据集。
  - 模型类型 ：训练具有更多参数的大型复杂模型通常比训练较小的模型花费更长的时间。
- **Q：我需要微调多少个示例？**

  生成一个好的微调模型所需的样本数量取决于几个因素，包括：

  - 您的任务与预训练知识的差异程度
  - 微调数据集的质量和多样性
  - 您选择的基础模型的大小，即与较大的基础模型相比，较小的基础模型可能需要稍大的训练数据集

    建议至少推荐几百个示例，但根据经验，数据集数量范围控制在 1k-2k 获得的结果最佳。
