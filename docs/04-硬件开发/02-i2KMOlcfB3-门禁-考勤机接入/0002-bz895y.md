# 蓝牙配网接入

## 蓝牙HAL对接接口

### **头文件**

```
#include "dtiot_ble_hal_service.h"
```

### **蓝牙回调注册**

**场景：**对接蓝牙HAL时候注册回调

**函数定义：**

```
int (*init)(dtiot_ble_hal_callback_t *callback);
```

**参数：**

```
typedef struct dtiot_ble_hal_callback_s dtiot_ble_hal_callback_t;

struct dtiot_ble_hal_callback_s {
  int (*start_advertising)(int interval, int rssi_level, int len, unsigned char* data);
  int (*update_advertising)(int interval, int rssi_level, unsigned char* data);
  int (*stop_advertising)();
  int (*notify_characteristic_changed)(int length, unsigned char* data);
};
```

### **蓝牙开始广播**

**场景：**蓝牙HAL回调三方开始广播的接口，传入参数包含广播的间隔和广播的内容。

**函数：**

```
int (*start_advertising)(int interval, int len, unsigned char* data);
```

### **蓝牙停止广播**

**场景：**蓝牙HAL回调停止广播的接口

**函数：**

```
  int (*stop_advertising)();
```

### **蓝牙发送数据**

**场景：**蓝牙HAL回调发送数据接口。蓝牙设备作为BLE的Server端采用Notify模式向手机端(Client)发送数据。

**函数：**

```
  int (*notify_characteristic_changed)(int length, unsigned char* data);
```

### **蓝牙接收数据**

**场景：**三方接收到蓝牙数据后，调用蓝牙HAL的接口完成数据的传递。

**函数：**

```
  int (*on_characteristic_write_request)(int length, unsigned char* data);
```

## 蓝牙配网绑定接口

### **头文件**

```
#include "dtiot_netconfig_bind_service.h"
```

### **蓝牙绑定**

#### **启动蓝牙绑定**

**场景：**启动蓝牙绑定，注册业务回调**函数：**

```
int (*ble_bind_start)(dtiot_ble_bind_callback_t *callback);
```

**参数:**

```
typedef struct dtiot_ble_bind_callback_s dtiot_ble_bind_callback_t;

struct dtiot_ble_bind_callback_s {
    //获取设备侧的wifi 列表
  int (*get_wifi_list)(void (*on_get_wifi_list)(int length, char* data));
  //连接wifi
  int (*connect_wifi)(char* ssid, char* password);
};
```

#### **停止蓝牙绑定**

**场景：**停止蓝牙绑定**函数：**

```
  int (*ble_bind_stop)(void);
```

### **设备配网成功**

**场景：**待wifi连接成功后，设置网络状态

**函数：**

```
int (*set_net_status)(int net_status);
```
