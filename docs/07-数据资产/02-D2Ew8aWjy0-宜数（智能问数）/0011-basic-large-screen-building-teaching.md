## **申请搭建权限**

1. 首次使用时，单击“从空白创建”弹窗提示“申请使用权限”。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7770954371/p890570.png)
2. 单击“去申请”，跳转到数据资产平台申请普通使用权限。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7770954371/p890571.png)
3. 发给管理员进行审批，通过后即可使用。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7770954371/p890572.png)
