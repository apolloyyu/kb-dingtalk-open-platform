# 概述

如果你想要了解链接增强和它的开放能力，你可以依据本文档了解链接增强。

## 什么是链接增强

在我们日常工作中会发送链接到钉钉会话中，如果我们需要访问目标链接的话需要点击链接并跳转目标页面。链接增强能力实现了钉钉聊天中的链接转换能力，接入后可以实现链接自动识别并转换成卡片。用户可以直观的查看卡片的内容信息，并且可以借助卡片的交互能力直接在卡片上实现业务操作。

## 链接增强使用场景

### 普通链接

以前发到钉钉会话中的链接展示只会为纯链接：

![链接增强链接 ](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1621872871/p481566.png)

### 链接增强

发送纯链接到会话内的场景皆可接入链接增强能力，如图片/文字/视频链接、审批、数据统计、表单收集等各种链接。

- 图文链接转卡片，展示网页信息

  ![链接增强网页信息](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1621872871/p481567.png)
- 审批链接转卡片，直接交互

  ![审批链接转卡片](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1621872871/p481568.png)
- 数据链接转卡片，展示数据信息
