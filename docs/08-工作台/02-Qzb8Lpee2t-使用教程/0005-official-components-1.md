# 官方组件

为满足千企万人的共性需求，钉钉平台提供了即拖即用的官方组件，让企业用户更简单、快捷的设计和搭建自定义工作台。

## **布局组件**

![1108布局组件.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5255107871/p736187.png)

### **分栏布局**

作为最重要的布局组件之一，用好分栏布局可以让你的工作台非常整齐、美观。参看 [巧用分栏布局](https://alidocs.dingtalk.com/i/p/e3RmQjoQdZnb5GaP/docs/b9Y4gmKWreL2ol9yt1LGpMxl8GXn6lpz)

- 支持配置分栏布局、内容对齐方式、宽高、外侧间距、内侧间距、颜色与填充。
- 分栏布局支持多重嵌套，加上分栏布局自身的模式配置，可以让工作台呈现任意类型的布局。不过一般不建议嵌套超过3层。

### **Tab容器**

- 支持配置标题、Tab对齐方式、底部选中条宽度、宽高、外侧间距、内侧间距、边框宽度、圆角、颜色与填充。
- 支持自行配置Tab选项。

## **基础组件**

![1108基础组件.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5255107871/p736191.png)

### **公告**

- 支持配置展示条数、图标、宽高、外侧间距、颜色与填充。
- 内容无需配置，在预览和客户端使用时会自动展示，数据取自官方公告应用。

### **公告轮播**

- 支持配置播放间隔、宽高、外侧间距、内侧间距、颜色与填充。
- 内容无需配置，在预览和客户端使用时会自动展示，数据和标准工作台公告轮播自动保持一致。

### **Banner轮播**

- 支持配置显示分页符、播放间隔、图片缩放模式、宽度、外侧间距、内侧间距、圆角。
- 自定义配置Banner内容，支持图片、标题、链接。

### **宫格**

- 支持配置宫格布局、格间距、图片缩放模式、宽高、外侧间距。
- 自定义配置宫格内容，支持应用、快捷方式、纯图片3种。
- 大部分三方应用都支持在PC端打开。若需要自行添加可以在PC端打开的快捷链接，例如将钉钉文档、钉钉云盘的地址添加为应用放在应用列表组件中，可以使用通过，创建后在宫格选择应用中添加应用时即可进行添加。

### **资讯卡片**

- 支持配置资讯条数、资讯高度、样式、图片缩放模式、宽高、外侧间距、内侧间距、边框宽度、圆角、颜色与填充。
- 自定义数据配置：

  - 新版数据流配置：详见 [工作台数据流使用指南](https://alidocs.dingtalk.com/i/p/Qrkoz3py2breX6L73RmQyZlK8Qg3dmaP)。
  - 老版数据配置：

    - 公告应用：支持选择公告分类。
    - 自定义接口：配置数据源之后，在此处可以选择对应的数据源进行展示，详见[官方组件数据格式](0014-qbmg52.md)。
    - 连接器：输入连接平台创建的连接器Id，在数据源列表中选择对应执行动作即可。
    - 手工配置：支持配置图片、标题、链接、发布人。

### **文本组件**

- 自定义配置内容、字号、字重、对齐，可作为标题、段落、说明等灵活使用。配合分栏组件，位置更灵活。
- 支持配置宽度、外侧间距、内侧间距、圆角、颜色与填充。

## **应用列表类组件**

![1108应用列表类组件.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5255107871/p736203.png)

### **最近使用**

- 支持配置标题、Icon缩放比例、宽高、外侧间距、内侧间距、边框宽度、圆角、颜色与填充。
- 内容无需配置，在预览和客户端使用时会自动展示工作台上的最近使用应用数据。

### **我的常用**

- 支持配置标题、Icon缩放比例、宽高、外侧间距、内侧间距、边框宽度、圆角、颜色与填充。
- 内容无需配置，在预览和客户端使用时会自动展示“我的常用”数据，自动和常用页面的“常用应用”数据保持一致，且用户个人可在客户端进行管理切换“手动管理”、“最近使用”两种模式。

### **应用列表**

- 支持配置标题、Icon缩放比例、宽高、外侧间距、内侧间距、边框宽度、圆角、颜色与填充。
- 自定义配置应用数据，在设计器中展示全部应用数据，在预览和客户端使用时会过滤可见性后展示剩余应用数据。
- 大部分三方应用都支持在PC端打开。若需要自行添加可以在PC端打开的快捷链接，例如将钉钉文档、钉钉云盘的地址添加为应用放在应用列表组件中，推荐使用[网页应用配置访问链接](../../01-应用开发/01-XOnnmGCTbn-开发指南/0035-application-visible-range.md#section-jxv-6mx-jw2)，创建后在应用列表中添加应用时即可搜出来。

### **全员常用**

- 支持配置标题、Icon缩放比例、宽高、外侧间距、内侧间距、边框宽度、圆角、颜色与填充。
- 内容无需配置，在设计器中、预览和客户端使用时会自动展示工作台上的全员常用数据，自动和标准工作台的全员常用数据保持一致。

### **全部应用**

- 支持配置标题、宽高、外侧间距、内侧间距、边框宽度、圆角、颜色与填充。
- 内容无需配置，在预览和客户端使用时会自动展示全部应用列表的数据，自动和标准工作台的全部应用列表（含未分组）数据保持一致。

### **我的/全员**

- 支持配置显示名称、全部应用入口开关、各项Tab配置、宽高、外侧间距、内侧间距、边框宽度、圆角、颜色与填充。
- 内容无需配置，在预览和客户端使用时会自动展示数据，“我的”部分数据和我的常用组件一致，“全员”部分数据和全员常用数据基本一致。

### **其他应用**

- 支持配置标题、宽高、外侧间距、内侧间距、边框宽度、圆角、颜色与填充。
- 内容无需配置，自动填充微应用数据（工作台快捷方式、审批/日志模板等不属于微应用），填充逻辑：如果微应用在当前页面的任何一个应用列表类组件（**我的/全员、全员常用**除外）不存在时，则会被放置到其他应用组件中。其他应用组件方便用户找到已安装但未被放置到分组中的应用。
