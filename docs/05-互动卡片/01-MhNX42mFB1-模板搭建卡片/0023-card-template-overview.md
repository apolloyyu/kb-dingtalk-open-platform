# 概述

本文将有助于你理解「卡片模板搭建器」的概念以及搭建器界面各部分的功能。

## **什么是卡片模板搭建器**

钉钉卡片模板搭建器是一个在线可视化搭建卡片的平台。开发者通过简单的拖拽、配置即可完成卡片模板的搭建。同时，搭建器提供了丰富的组件和预置卡片模板，帮助开发者更加方便、快速地接入互动卡片。

## **搭建器界面总览**

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6782293761/p543111.png)

如上图所示，卡片模板搭建器的界面共分为以下 5 个部分：

| **序号** | **区域名称** | **核心功能** |
| --- | --- | --- |
| ① | 功能菜单 | 切换不同的功能面板。 |
| ② | 功能面板 | 提供大纲树、组件库、数据源等功能模块。 |
| ③ | 模拟器 | 预览卡片在不同客户端环境下的渲染效果。 |
| ④ | 组件属性设置面板 | 调整选中组件的内容、样式和事件。 |
| ⑤ | 操作栏 | 模板级别的导入、导出、复制、保存和发布。 |

## **功能菜单与面板详解**

功能面板及对应功能如下：

| **面板** | **功能描述** |
| --- | --- |
| **大纲树** | 可以查看和调整模板的组件层次结构。 |
| **组件库** | 可以查找组件、拖动组件到编辑器画布中。 |
| **区块组件库** | 提供基于基础组件组合而成的复合组件，可以直接添加到编辑器画布中。 |
| **预设模板** | 提供预设卡片模板列表，可以快速导入到编辑器画布中。 |
| **数据源** | 可以在此编辑卡片变量和变量的模拟数据。 |
| **版本更新日志** | 卡片模板搭建器的更新日志，可以在这里查看新版本搭建器的重要改动。 |

## **模拟器**

在模拟器中你可以在配置模拟的客户端环境、暗黑模式、版本号以及语言，同时也可以对组件进行编辑和布局的调整；结合模拟数据和预览模式，可以让你在模拟器提前感知卡片的实际渲染效果。

## **组件属性设置面板**

在属性设置面板中，开发者可以通过设置组件的属性，来调整组件的样式及内容。

| **属性类型** | **说明** |
| --- | --- |
| **内容** | 展示该物料常规的属性 |
| **样式** | 展示该物料样式的属性 |
| **事件** | 如果该物料有声明事件，则会出现事件面板，用于绑定事件 |

更多定制化的属性，具体可以在组件的文档中查看。

## **操作栏**

操作栏主要是对卡片模板级别的操作，提供模板的导入、导出、复制以及保存和发布等功能。
