## Request headers
- none

## Path params
- none

## Query params
- access_token (String, required): 调用服务端API的应用凭证，通过获取企业内部应用的access_token接口获取。

## Body
- event (Event, required): 日程创建对象。
- attendees (Attendee[], required): 日程参与者，参与者最大人数为100，包括组织者。
- userid (String, required): 参与日程的员工userid。
- calendar_id (String, required): 目前只能传primary，表示创建的日程在“我的日程”下。
- end (DateTime, required): 结束时间。
- organizer (Attendee, required): 日程组织者信息。
- start (DateTime, required): 开始时间。
- summary (String, required): 日程主题。
- agentid (Number, required): 应用对应的AgentId。
- optional: description(String), date(String), timestamp(Number), timezone(String), reminder(OpenCalendarReminderVo), method(String), minutes(Number), location(LocationVo), latitude(String), longitude(String), place(String), notification_type(String)

## Returns
- optional: result(Event), attendees(Attendee[]), userid(String), calendar_id(String), description(String), end(DateTime), date(String), timestamp(Number), timezone(String), event_id(String), organizer(Attendee), start(DateTime), summary(String), reminder(OpenCalendarReminderVo), method(String), minutes(Number), location(LocationVo), latitude(String), longitude(String), place(String), notification_type(String), success(Boolean), errcode(Number), request_id(String), errmsg(String)

## Limits
- 日程参与者，参与者最大人数为100，包括组织者。
- 目前只能传primary，表示创建的日程在“我的日程”下。
