# 概述

本文档介绍什么是钉钉应用市场，如何进入钉钉应用市场以及应用市场接口能力。

## 什么是钉钉应用市场

钉钉应用市场不仅为企业各职能部门提供营销、流程、管理工具等各类应用服务；还提供工商、财税、法律、知识产权等企业服务，一站式解决企业需求。钉钉企业组织在完成[合作全流程指引](../07-TjCzIgfQs3-平台服务/0027-isv-cooperation-guide.md)后，成功入驻为应用服务商，可以创建并开发钉钉应用上架到钉钉应用市场，通过免费或者付费的方式提供给其他钉钉组织开发使用。

开发者可通过以下方式进入应用市场：

- 手机端：钉钉手机客户端-工作台-右上角应用中心

  ![iShot2022-02-07 14](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4632084461/p397833.png)
- PC端：钉钉PC客户端-工作台-右上角应用中心

  ![iShot2022-02-07 14](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2241993871/p397835.png)

## **什么是应用内购**

应用内购是指产品方案商在开发的**第三方企业应用**中，集成虚拟商品或服务的购买能力，使用户能够在钉钉客户端内完成下单与支付。

主要关系模型如下：

- 一个**第三方企业应用**可拥有多个**内购商品**（1:N）
- 一个**内购商品**仅归属于一个应用（N:1）
- 一个**内购商品**可定义多个**内购规格**（1:N）

### **背景**

随着企业数字化需求的增长，越来越多的产品方案商通过钉钉平台提供定制化应用服务。为了实现商业化闭环，钉钉开放了**应用内购**能力，允许开发者在自研的第三方企业应用中售卖虚拟商品或服务（如会员时长、使用额度等），并由钉钉统一完成支付与订单管理。

该机制不仅提升了用户在钉钉生态内的购买体验，也保障了交易的安全性和合规性，是构建可持续SaaS商业模式的重要基础设施。

- **内购**

  即应用内购买，指产品方案商在其开发的应用中提供的增值服务购买能力。用户可在使用过程中直接完成付费，获取特定功能或资源。
- **第三方企业应用**

  产品方案商开发的提供给企业的微应用或小程序。
- **内购商品**

  应用内售卖的商品，归属于第三方企业应用，一个内购商品仅允许在一个应用内售卖。
- **内购规格**

  内购商品的属性，是售卖的最小单位。一个内购商品可以有多个内购规格。

  内购规格的“规格码”属性，是内购规格的唯一标识，在钉钉[开发者后台](http://open-dev.dingtalk.com/)创建内购规格生成，全局唯一且不可修改。

### **适用场景**

- **周期型服务开通**：企业按年/月订阅高级功能，例如“CRM系统包年服务”。
- **消耗型资源购买**：员工按需购买可核销的服务次数，例如“会议预约券”、“差旅打车额度”。
- **个人名义采购**：非管理员以个人身份购买与企业无关的服务，如个人学习课程。
- **企业内部报销类消费**：非管理员代表企业下单，费用归属企业，便于后续对账和审批。

### **收费模式**

目前支持两种收费模式：

- **周期型**：购买后在有效期内持续使用，每个企业在有效期内只能购买一次。
- **消耗型**：不限购买次数，每次使用后进行核销，适合按量计费场景。

典型实现场景：用户在钉钉应用市场开通某第三方企业应用时，选择所需规格并完成支付，即可立即启用对应服务。例如：

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2241993871/p817802.png)

### **关于用户购买**

- 目前周期型内购商品只支持管理员购买，消耗型商品可配置支持普通员工购买。
- 第三方企业应用若适配PC端，可在PC端购买内购商品
- 用户购买方法：

  - 安卓端可以直接购买
  - IOS端无法直接在手机端支付，需要通过**天元系统**提单。

    > **[!NOTE]**
    >
    > 天元系统主要用于钉钉第三方应用的直销、分销的系统，能够快速管理客户，提供创建客户、提单购买、订单支付等相关功能，更多详情请参考[天元系统](https://www.yuque.com/xlq/xlq/ssr8nq)。

### **周期型内购商品**

#### **周期型内购商品收费模式**

周期型内购商品购买后有效期内可以一直使用，每个企业在产品有效期内仅能购买1个，例如“企业包年CRM服务，一年内有效”。

周期型内购商品有两个规格关系：

- **各规格独立**：各个规格间不存在升降级关系。
- **规格有升级关系**：商品支持多规格, 且可以从低规格升级到高规格, 低规格剩余费用会抵扣高规格价格, 但不可降级。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2241993871/p492852.png)

#### **周期型商品规格类型**

周期型商品，只支持**固定规格**，即每个规格的价格固定。

![iShot2022-09-20 10](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2241993871/p492534.png)

### **消耗型内购商品**

#### **消耗型内购商品收费模式**

消耗型内购商品购买个数不限，每次使用后进行核销，例如“汉堡兑换券，每买1个汉堡消耗1张汉堡兑换券”。

消耗型内购商品可配置是否支持个人购买。

- **不支持个人购买**：只有企业管理员才可以在应用市场购买开通该第三方企业应用。
- **支持个人购买**：企业管理员和非管理员都可以在应用市场购买并开通该第三方企业应用。

  **个人购买**分为以下两种方式：

  - **纯个人购买：**订单归属于个人，与个人所属的企业无关，企业管理员看不到这类订单。比如以个人名义买一张机票或者打车。
  - **企业内非管理员购买：**订单归属于企业，企业管理员可以看到这类订单，可以理解为非管理员以公司名义下单，比如团结出行或者为公司采购一批办公物品。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3234827661/p492805.png)

#### **消耗型商品规格类型**

消耗型商品，支持固定规格和非固定规格。

- **固定规格**：即每个规格的价格固定，如下图所示。

  ![iShot2022-09-20 10](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2241993871/p492538.png)
- **非固定规格**：即无固定价格，可自定义数值，使用流程请参考下文**非固定规格实现流程。**

  ![iShot2022-09-20 10](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2241993871/p492544.png)

#### **非固定规格实现流程**

1. 创建**消耗型**内购商品时，将规格类型勾选为**非固定规格**。

   > **[!IMPORTANT]**
   >
   > 非固定规格只支持**消耗型**内购商品。

   ![iShot2022-09-20 10](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2241993871/p492544.png)
2. 内购商品审核上架后，调用[获取内购商品SKU页面地址](0883-obtain-the-address-of-the-product-sku-details-page.md)接口，使用参数extend\_param指定商品价格。
3. 调用接口指定商品价格后，用户侧下单界面如下图所示。

   ![iShot2022-09-20 10](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2241993871/p492578.png)
