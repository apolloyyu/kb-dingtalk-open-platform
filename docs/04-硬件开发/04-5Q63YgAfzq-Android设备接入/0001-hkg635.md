# 设备初始化及管理

本文介绍设备初始化SDK的使用方法，以及如何注册设备绑定、解绑状态回调，帮助开发者快速集成钉钉IoT能力。

## 引入SDK依赖类

请确保项目中已引入以下类：

```
import com.alibaba.dingtalk.inside.bind.DingTalkInsideSdk;
```

## 设备初始化

**场景：**本方法用于初始化sdk，需要传入产品的信息和设备的信息。产品的主要信息由钉钉颁发给三方，设备的信息由三方提供。

**函数**：

```
public static void init(@NonNull Context c, @NonNull DeviceModel deviceModel);
```

**参数：**

```
public class DeviceModel {
    private String productKey; //产品KEY，在钉钉开放平台创建
    private String productSecret; //产品secret，在钉钉开放平台创建
    private String deviceName; //一机一码的情况下需要传入dn
    private String deviceSecret; //可选
    private String sn; //设备序列号
    private String mac; //设备mac
    private int platform; //设备接入的平台信息，包括阿里IoT、钉钉IoT平台等
    private int bindMethod; //设备绑定的方式
    private int qrType; //静态二维码类型，是一型一码还是一机一码
}
```

## 设备绑定解绑回调

**场景：**注册设备绑定/解绑状态回调，绑定状态发生改变时候会通知注册方。

**函数**：

```
public static void addBindStatusListener(BindStatusListener listener);
```

**参数**：

```
public interface BindStatusListener {
    void onDeviceBind(); // 设备绑定时回调
    void onDeviceUnbind(); // 设备解绑时回调
}
```

## 设备查询绑定状态

**场景**：主动获取绑定解绑状态

**函数**：

```
public static boolean isBind();
```

## 设备解绑

**场景**：第三方主动解绑设备

**函数**：

```
public static void unbindDevice();
```
