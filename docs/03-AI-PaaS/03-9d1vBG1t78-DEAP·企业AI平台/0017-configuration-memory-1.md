# 调用授权

## **操作流程**

1. 进入 [DEAP后台](https://deap.dingtalk.com/#/sub-app/api-key) 在API-key模块下，点击**新增API-key**按钮，创建一个新的API Key。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6309863971/p1109881.png)
2. 在弹窗中，弹入API-key描述，最后单击**确定**。

   > **[!NOTE]**
   >
   > 描述主要用于解释当前API-key的适用场景或用于等信息，最多200个字符。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6309863971/p1109882.png)
3. 创建成功后，点击**权限设置**，进入权限设置界面。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6309863971/p1109883.png)
4. 进入权限配置界面后，定位需要的权限组，然后点击**授权**。

   - 企业模型调用授权：需要授权**大模型对话时权限**，下图中②。
   - 企业AI助理调用授权：需要授权**DEAP智能体响应**，图中中①。

     ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6309863971/p1109886.png)
5. 在开启**启用授权**，并选择需要调用的模型后，单击**保存**即可。

   > **[!NOTE]**
   >
   > 若申请的是**企业AI助理调用授权**，则选择智能体，和下图中的模型选择有所区别，但流程不变。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6309863971/p1109885.png)
