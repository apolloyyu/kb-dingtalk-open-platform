# 注释

注释方法和 Javascript 一致，可以使用以下方法对 SJS 代码进行注释：

```
// page.sjs
// 方法一：这是一个单行注释

/*  方法二：这是一个多行注释中间的内容都会被注释 */
let h = 'hello';
const w = 'dingtalk';
```
