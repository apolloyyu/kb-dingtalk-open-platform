# 配置网页应用

为了进行网页应用的开发，你需要完善网页应用的配置信息。你可以依据本文档操作流程来完成网页应用信息的配置。

## 适用对象与权限说明

本文档适用于**需要开发网页应用**的开发者。

关键信息如应用 ID 可在【开发者后台】>【应用详情】>【凭证与基础信息】中查看。

更多关于应用类型的说明，请参考：[应用类型详解](0002-application-type-introduction.md#5b2cb72d3bzh4)。

## **前提条件**

在配置网页应用信息前，需要完成[应用创建与配置](0007-create-application.md)流程。

## **操作步骤**

1. 登录[开发者后台](https://open-dev.dingtalk.com/#/)，单击目标应用，进入应用详情页。
2. 单击**应用能力** > **网页应用** > **编辑标识，**进入网页应用配置信息页面。
3. 根据业务需求填写以下配置项：

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6259836771/p1068414.png)

   | **配置项** | **是否必选** | **配置说明** |
   | --- | --- | --- |
   | 移动端首页地址 | 否 | 输入可以在钉钉移动端的工作台上打开网页应用的地址。链接地址必须以 http 或 https 开头。  **[!NOTE]**  - 必须与PC端首页地址二选其一。 - 若应用未配置移动端首页地址，应用发布后，移动端钉钉工作台不会进行展示。 |
   | PC端首页地址 | 否 | 输入可以在钉钉 PC 端的工作台上打开网页应用的地址。链接地址必须以 http 或 https 开头。  **[!NOTE]**  - 必须与移动端首页地址二选其一。 - 若应用未配置PC端首页地址，应用发布后，PC端钉钉工作台不会进行展示。 |
   | 管理后台地址 | 否 | 输入管理员在[钉钉管理后台](https://oa.dingtalk.com/)访问该应用的地址。 |
4. 配置完成后，单击**保存**按钮提交更改。
5. （可选）启用网页应用的酷应用场景。

   > **[!NOTE]**
   >
   > 启用前，必须确保应用首页地址已输入。

   如果应用首页地址发生变更，必须手动更新对应酷应用配置。关于如何配置，可参考[接入链接增强](0068-access-link-enhancements-coolapp.md)。

   - 应用名片：启用后，系统会自动创建一个链接增强酷应用，并自动将应用名称、应用简介和应用首页地址解析在卡片内容中。如需自定义应用名片的卡片样式，点击**查看**跳转到链接增强酷应用，然后点击**前往卡片搭建器**更新卡片使用的模板。相关信息，可参考[互动卡片模板编辑器](../../05-互动卡片/03-MhNX42mFB1-模板搭建器/0001-card-template-overview.md)。
   - 应用捷径：如果想在输入框（如聊天输入框、搜索输入框）内通过快捷指令“/”唤起H5微应用，点击**启用**应用捷径。

     启用后，系统会自动创建一个快捷指令酷应用，并自动将应用名称、应用简介和应用首页地址解析为指令名称、指令简介和指令执行后打开链接。

## **后续步骤**

配置完成后，你可以进行[发布应用](0019-publish-dingtalk-application.md)，使其对组织内成员可见并可用。如需进一步开发网页应用前端或服务端功能，请参考：

- [开发网页应用前端](0033-develop-webapp-frontend.md)
- [开发网页应用服务端](0034-develop-webapp-backend.md)
