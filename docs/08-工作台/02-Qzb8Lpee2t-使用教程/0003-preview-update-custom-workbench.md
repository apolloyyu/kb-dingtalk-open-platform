# 预览、发布自定义工作台

本文档介绍预览和发布自定义工作台的步骤。

## **名词解释**

自定义工作台数据状态分为草稿态数据、待启用数据和启用态数据三类。

- **草稿态数据：**在设计器内编辑后保存的数据，即为草稿态数据，每次编辑保存后，草稿态数据即变化。
- **待启用数据：**在设计器内点击发布按钮后的数据，即发布为待启用数据，只修改设计器，不点击发布，则不会修改待启用数据。在工作台项目详情页面点击启用工作台按钮，即会将当前的待启用数据复制生成启用态数据，启用到线上影响用户组织。
- **启用态数据：**在工作台项目详情页点击启用按钮后，用户组织使用的数据。

## **操作流程**

### **预览草稿态数据**

在工作台设计器内点击右上角的**预览**按钮，会有弹窗提示打开钉钉，点击后跳转的钉钉工作台页面，预览草稿态数据效果。

![1108设计器预览.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3255107871/p736276.png)

### **发布草稿态数据**

在自定义工作台设计器内点击右上角**发布**按钮，即可将草稿数据发布为待启用数据。

![PC设计器](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3255107871/p618532.png)

### **预览待启用数据**

在**工作台项目详情页**，点击该页面上的 **点击预览效果**，即可预览页面的待启用数据

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3255107871/p534094.png)
