# 接入机器人能力

如果你想将酷应用与机器人应用结合，你可以依据本文档进行快速了解。

群聊酷应用机器人在群内的核心作用，不仅可以为成员推送各类消息，而且它也提供了一系列的消息管理和交互能力。

![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6956817661/p508736.png)

当群聊酷应用机器人同时接入发消息和收消息的能力时，群聊酷应用机器人就具备与用户进行消息对话的能力了，我们称为对话式机器人。当你需要了解如何接收消息，详情参考[机器人接收消息](0080-robot-receive-message.md)，当你需要了解如何发送消息，详情参考[机器人回复/发送消息](0081-robot-reply-and-send-messages.md)。
