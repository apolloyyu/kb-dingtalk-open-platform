# 微应用页面支持横屏

通过**dd\_orientation**参数设置微应用页面支持横屏。

## 使用说明

| **客户端** | **Android** | **iOS** | **PC** |
| --- | --- | --- | --- |
| 支持说明 | 支持 | 支持 | 不支持 |

在url后面拼接`dd_orientation=landscape`参数，示例如下：

```
http://abc.xyz?dd_orientation=landscape
```
