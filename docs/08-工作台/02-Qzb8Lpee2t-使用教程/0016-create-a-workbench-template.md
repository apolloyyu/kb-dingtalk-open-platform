# 创建工作台模板

本文介绍了如何创建自定义工作台模板的操作步骤。

## 步骤一：创建模板

1. 登陆[开发者后台](https://open-dev.dingtalk.com/)。
2. 依次选择**定制服务 > 工作台定制 > 工作台模板**，单击**体验一下，创建模板**。

   ![创建模板](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9843658161/p262495.png)
3. 填写模板名称、描述、预览图等模板信息后，工作台模板即可创建成功。

   > **[!NOTE]**
   >
   > 模板信息可进行修改。

   ![创建模板](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8910451161/p230065.png)

## 步骤二：配置模板

选择创建的模板，单击右侧**配置**按钮进入设计器，在设计器界面，对模板进行配置。

![工作台模板配置](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7875729261/p306905.png)

## 步骤三：发布模板

配置完成后，单击设计器右上角**发布**，此时工作台模板发布可用，即在工作台创建时可选择。
