# 最佳实践：一站式运营参谋，赋能组织治理提效

## **案例介绍**

某新能源企业的日常工作沟通和业务流程已经在钉钉上运行，各种自建系统也接入了钉钉工作台，但业务系统数据分散，长期存在数据孤岛问题，为了支持企业数字化转型，提升内部管理协同效率，迫切需要一套数据化运营管理工具。

## **产品方案**

基于宜数的互动大屏、工作台数据组件、IM订阅推送等能力，能够零代码、快速提供一站式的运营数字参谋：

- 基于高级数据大屏能力，搭建企业全局运营效率监控大屏，比学赶超；
- 基于工作台数据组件能力，打造企业数据工作台，让每天工作从数据开始；
- 基于IM订阅送能力，打造指标预警机制，让业务异动最快时间被发现。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1245754371/p889110.png)

## **产品能力**

因为本方案涉及三大基础产品能力（互动大屏、工作台数据组件、IM订阅推送）和企业协同数据资产，这里不对具体产品能力操作流程进行详细介绍，可参考各能力操作手册，仅对整体搭建逻辑进行说明。

### **企业协同数据资产**

平台提供企业在使用钉钉过程中沉淀的各类高质量数据资产，覆盖企业办公数字化、组织数字化、业务数字化等各方面，可支持进行内部协同效率运营分析。具体可参见[数据资产](0020-data-assets-overview.md)。
