# 蓝牙配网接入

本文档旨在指导开发者完成钉钉蓝牙配网功能的完整接入流程，通过本SDK，可实现硬件设备与钉钉账号的安全绑定，广泛应用于智能办公设备（如考勤机、门禁、打印机等）的快速配置场景。

## 引入SDK依赖类

请确保项目中已引入以下类：

```
import com.alibaba.dingtalk.inside.bind.DingTalkInsideSdk;
```

## 启动蓝牙绑定

**场景**：启动蓝牙绑定

**函数**：

```
public static void bleBindStart();
```

## 停止蓝牙绑定

**场景**：停止蓝牙绑定

**函数**：

```
public static void bleBindStop();
```

## 示例代码

示例代码仅供参考，请根据实际情况进行开发。

```
// 初始化SDK（通常在Application中完成）
DingTalkInsideSdk.init(context);

// 用户点击“开始配网”
void onBleBindClick() {
  if (!isBluetoothEnabled()) {
    showTip("请先开启蓝牙");
    return;
  }
    
  // 注册状态监听（根据实际SDK支持方式）
  registerBindStateReceiver();

  // 启动蓝牙绑定
  DingTalkInsideSdk.bleBindStart();

  // 显示加载状态
  showLoading("正在搜索设备...");
}

// 用户点击“取消”
void onCancelBindClick() {
  DingTalkInsideSdk.bleBindStop();
  hideLoading();
}

// 接收绑定结果广播
void onReceive(Context context, Intent intent) {
  String state = intent.getStringExtra("state");
  if ("success".equals(state)) {
    String deviceId = intent.getStringExtra("device_id");
    showToast("绑定成功: " + deviceId);
  } else if ("failed".equals(state)) {
    String errorMsg = intent.getStringExtra("error_msg");
    showToast("绑定失败: " + errorMsg);
  }
}
```
