# 概述

本文介绍了自定义工作台的基本概念和模板与工作台之间的功能差异。

## 简介

工作台模板并非对客户实际配置和交付的工作台，其作用主要是为了将常用的工作台样式进行提前设计和预置，以便方便为客户快速进行配置，提高交付效率。

## 模板与工作台的功能差异

因工作台模板与客户无关联，仅为工作台的样式“样板间“，故工作台模板中的部分数据设置与工作台之间存在差异，详情如下：

| 数据项 | 所属组件 | 模板中处理方式 |
| --- | --- | --- |
| 应用列表中“添加应用” | 应用列表 | - 工作台中可添加的是当前客户组织中已开通的应用。 - 模板中可添加当前服务商组织已开通的应用。 |
| 应用名称修改 | 应用列表 | 无法进行修改。 |
| 快捷方式配置 | - 宫格 - 应用列表 | 暂无法修改，后续将支持。 |
| 外部链接 | - 悬浮组件 - Banner轮播 | 暂无法修改，后续将支持。 |
| 公告 | - 公告 - Banner轮播 | 无法进行修改。 |
| 官宣号 | Banner轮播 | 无法进行修改。 |
