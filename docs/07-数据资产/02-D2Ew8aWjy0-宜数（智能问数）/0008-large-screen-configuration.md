# 大屏配置

> **[!NOTE]**
>
> **高级版**可使用。

## **概述**

开启互动大屏后，在助理对话界面能够快速进入互动大屏连接页面，输入投屏码，连接到互动大屏，通过问数与大屏互动。

### **功能价值**

开启后，可以将智能问数助理与数据大屏联动，将问数结果在数据大屏呈现并进行互动，满足个性化数据分析诉求，让大屏数据“活”起来。

### **适用范围**

- 有研发能力的大型、中型企业。
- 有BI、大屏等数据可视化系统使用经验的人。

## **适用场景**

### **使用效果**

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8045754371/p888962.png)

### **配置流程**

1. 配置[数据源](0005-data-management-configuration.md)，进入智能问数配置页面。
2. 单击大屏配置，开启与大屏互动的能力。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8045754371/p889873.png)
3. 返回宜数页面，进入互动大屏页面搭建大屏，详情参考[互动大屏](0010-overview-2.md)。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8045754371/p889876.png)
4. 在大屏配置页面顶部打开“开启智能大屏互动”开关。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8045754371/p889878.png)
5. 完成搭建后，点击预览进入大屏，右上角显示投屏码。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8045754371/p889884.png)
6. 点击问数助理输入框上方的【大屏互动】快捷入口，弹出连接界面。

   > **[!NOTE]**
   >
   > 在 IM 里面使用问数助理时，【大屏互动】快捷方式无法展示，暂时仅支持LUI容器展示。

   ![智能问数大屏](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9080766871/p889893.png)
7. 输入大屏右上角的投屏码，点击投屏，如大屏右上角显示智能问数【已连接】，说明连接成功。

   ![image](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8045754371/p889897.png)
8. 通过问数LUI界面进行提问，大屏会同步展示结果。

   ![大屏效果](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9080766871/p889903.png)
9. 如果需要断开连接，手动点击断开，即可完成。

   > **[!NOTE]**
   >
   > 大屏连接上后，不会自动断开。

   ![断开大屏](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9080766871/p889906.png)
