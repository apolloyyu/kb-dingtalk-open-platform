# 小程序开发工具

小程序开发者工具（简称 IDE）是归属于支付宝的一站式小程序研发平台，提供编码、调试、测试、上传和项目管理等完整功能，全面支持钉钉小程序的开发与调试。

> **[!NOTE]**
>
> 该工具归属于支付宝开放平台，如需查看和下载该工具的其他使用信息，请前往[支付宝开放平台](https://opendocs.alipay.com/mini/02bzsm?pathHash=98121aa5)进行查看和下载。
