# 概述

本文档介绍什么是设备上钉，如何开通使用设备上钉，设备上钉接口能力等。

## 什么是设备上钉

设备上钉是将设备接入钉钉，从而实现设备的链接，实现我们从组织协同到人、机、智能协同的跨越。通过设备上钉，我们的设备可以自动发出报警信息，我们可以在群聊中处理设备的各类信息，实现人与机器的快速交互。![iShot2022-01-26 20](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4804919771/p395790.png)
