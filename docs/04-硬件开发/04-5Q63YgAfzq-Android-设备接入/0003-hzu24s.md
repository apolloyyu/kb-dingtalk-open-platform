# softap配网接入

softap配网是一种常见的物联网设备联网方式，适用于智能硬件（如考勤机、门禁设备、打印机等）首次连接企业Wi-Fi网络的场景。本文档介绍了softap配网SDK接入和启动、停止softap绑定。

## 引入SDK依赖类

请确保项目中已引入以下类：

```
import com.alibaba.dingtalk.inside.bind.DingTalkInsideSdk;
```

## 启动softap绑定

**场景**：启动softap绑定

**函数**：

```
public static void softapBindStart();
```

## 停止softap绑定

**场景**：停止softap绑定

**函数**：

```
public static void softapBindStop();
```
