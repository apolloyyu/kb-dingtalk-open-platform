# 概述

服务窗给组织提供强大的客户管理和业务服务能力，实现以客户为中心的一站式展示、沟通、管理平台，帮助连接组织内外。

## 什么是服务窗

服务窗是钉钉推出的一站式组织对外服务平台。企业可以通过服务窗管理后台进行配置，配置完成后，用户可以在钉钉上搜索并关注服务窗，与企业进行互动交流。

服务窗已经提供了自定义链接跳转、企业主页、资料库、发起客户工单等缺省功能，没有很强定制需求的企业只需要在服务窗管理后台进行简单配置即可直接使用。

- 管理员视角

  管理员在服务窗配置后台，进行可视化配置。

- 用户视角

  企业客户通过有强定制需求的企业，我们提供了自建服务窗应用的能力，它与服务窗集成后就可以获取服务窗上的联系人数据，从而满足个性化客户服务的诉求。

  ![4ff0f7c006334093935733f2fcc17ffc2113](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2615802261/p259688.png)![服务窗聊天界面](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2615802261/p278065.jpg)

服务窗还提供了以下支持：

- 集成客户管理、智能客服机器人、消息推送等应用。
- 接入自定义应用，开放授权登录、通知触达等能力。

## 如何开通服务窗

1. 申请服务窗。

   打开钉钉**通讯录**，进入**企业管理 > 互联平台 > 服务窗**提交申请。当提交了服务窗的基本资料后，钉钉会在1-3天内进行审核，审核通过后服务窗即申请成功。

   > **[!IMPORTANT]**
   >
   > 只有创建该组织的主管理员有申请权限。

   ![申请服务窗](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9644240161/p212654.png)
2. 配置服务窗。

   进入桌面版**钉钉工作台 > 服务窗应用 > 自定义菜单 > 欢迎语&自动问答 > 二维码**配置欢迎语和自动回复的知识库内容。

   ![配置服务窗](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9644240161/p212656.png)

## **客户案例**

钉钉服务窗能够快速连接与客户之间的业务往来，企业可通过服务窗向自己的客户提供业务服务，客户在新增的服务窗中建立与企业间的联系，实现简单与快捷的下单和订货。

### **案例一：经销商管理**

**杭州百事可乐饮料有限公司**

产品价值：通过钉钉服务窗服务经销商，让物流送货流程全面数字化。

- **过去**

  经销商下了订单后，公司通知承运商送货，承运商安排司机，司机送到货后，拿着五联单找经销商的经理签字后再带回公司。

  遇到的问题：

  - 签收身份不明：五联单是谁签的，身份不确定。
  - 效率低：司机送到货，联系不上经销商经理，不能及时在五联单上签字确认。签字后不能及时向公司回传。
  - 风险高：安排其他人代签收时，经常出现事后扯皮，严重的还涉及到法律风险以及经济损失。
  - 追溯难：物流送没送、送多少、客户拒收了多少等行为没人知道。

  ![送货单](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6946077161/p260762.png)
- **现在**

  百事可乐可以和经销商、承运商在服务窗通过表单对该业务流程进行高效协同，建立高效清晰可追溯的业务闭环，避免纠纷风险。

  ![p259704](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1376967161/p260605.png)![图二](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1376967161/p260611.png)

### **案例二：供应商管理**

**深圳市正君餐饮管理顾问有限公司**

产品价值：通过服务窗服务供应商，让供应商对账流程数字化。

- **过去**

  - 财务经常出现漏审核漏打款现象，给部分供应商留下拖欠贷款体感，透支企业信用。
  - 财务有大量录入工作，工作效率低下。
  - 供应商无法看到审批进度，经常催款，体验差。

  ![示例二](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1376967161/p260614.png)
- **现在**

  供应商通过服务窗自主提交对账申请，财务确认对账单审批通过后，直接对接到钉钉的付款系统付款。

  - 对账申请直接接入钉钉审批，财务在钉钉审批待办中即可操作，避免漏批。
  - 供应商可实时查看审批状态，体验好。
  - 审批通过后付款信息自动导入至付款系统，财务可直接付款，免除无谓的录入工作。

  ![示例二](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1376967161/p260617.png)

## 名词解释

- **组织**

  钉钉组织，可以是真实企业，也可以是教育机构，或者是一家夫妻店。
- **主管理员**

  组织的主管理员。
- **企业内部开发应用**

  企业用钉钉管理员工，需要提供一些应用给到员工使用，企业有IT能力可以自行开发。
- **服务窗**

  用户关注之后就可以和服务窗进行互动交流，服务窗归属真实组织架构。
- **虚拟组织**

  不可见的钉钉组织，存储关注服务窗的用户订阅关系，所有关注了服务窗的用户都会加入对应的虚拟组织，服务窗和虚拟组织是一对一的关系。
- **服务窗应用**

  企业用虚拟组织管理关注服务窗的用户数据，需要提供一些应用给到用户使用，支持企业自建或者委托产品方案商定制开发，这些应用需要基于虚拟组织开发。
- **知识库**

  专业高效的企业知识管理平台，可以帮你轻松搭建一个企业知识管理库，操作简单便捷，管理员添加成员后即可多人共享，实时同步，团队成员可以在其中记录内部协作产出的所有内容。
